# T002: `@mc/contracts`: schemas, types, validators, fixtures

Milestone M0 · Wave 0c · Depends on: T004 · Runs on: any OS

## Goal

Turn the JSON Schemas in `docs/contracts/` into the `@mc/contracts` package: schema
copies, generated TypeScript types, Ajv validators, fixtures, and a lock that fails when
a schema changes.

## Codes against

`docs/contracts/README.md` (names), `session.schema.json`, `ingest.schema.json`,
`api.schema.json`, `config.schema.json`, `vscode-bridge.md` sections 2-3 (to transcribe
`bridge.schema.json`), `ingest.md` section 7 (fixture list).

## Files (create or replace stubs)

`packages/contracts/schemas/{session,ingest,api,config,bridge}.schema.json`,
`packages/contracts/scripts/generate.mjs`, `packages/contracts/src/generated/*.ts`,
`packages/contracts/src/{index,validate}.ts`, `packages/contracts/contracts.lock.json`,
`packages/contracts/fixtures/ingest/*.json`, `packages/contracts/fixtures/ingest/raw/*.json`,
`packages/contracts/fixtures/sessions/*.json`, `packages/contracts/test/contracts.test.ts`,
`docs/checkpoints/T002.md`. Add script `"generate": "node scripts/generate.mjs"` to
`packages/contracts/package.json` (the one exception to not editing it).

## Do not touch

`docs/contracts/**` (copy, never edit), every other package.

## Steps

1. Copy the four `*.schema.json` files from `docs/contracts/` byte for byte.
2. Write `bridge.schema.json` (`$id .../bridge.schema.json`, `$defs.BridgeClientMessage`
   = oneOf hello/terminals/windowState/result; `$defs.BridgeServerMessage` = oneOf
   welcome/focusTerminal/focusAgentPanel), every object `additionalProperties: false`,
   every field from `vscode-bridge.md` required, types as shown there.
3. `scripts/generate.mjs`: `json-schema-to-typescript` `compile()` for each schema with
   `{ bannerComment: "// GENERATED by scripts/generate.mjs. Do not edit.", additionalProperties: false, unreachableDefinitions: true, $refOptions: { resolve: { file: true } } }`;
   a custom resolver maps `https://mission-control.local/contracts/<f>` to `schemas/<f>`.
   Output one file per schema in `src/generated/`. If the output for a schema with no root
   type (`api.schema.json`, `bridge.schema.json`) lacks its `$defs` types, then inside
   `generate.mjs` only (never in the schema file) compile a copy of the schema whose root
   is `{"anyOf": [{"$ref": "#/$defs/<Name>"}, ...]}` over every `$defs` name, and drop the
   generated root alias. Record which path you needed in the checkpoint.
4. `src/index.ts`: re-export the names in `docs/contracts/README.md` ("Exported TS
   names"). `Config` = the generated config type with every property made required
   recursively (`type DeepRequired<T>`; write it in `index.ts`); `ConfigFile` = generated
   as is. `IngestOrigin` = the `Origin` def; `ProcessInfo`; `OsNotification`.
5. `src/validate.ts`: one shared `Ajv2020` (`ajv/dist/2020.js`) instance with
   `allErrors: true, strict: false`, `ajv-formats` added, all five schemas added; export
   the validators of README.md with the `{ok, value} | {ok, errors}` shape; error strings
   are `"<instancePath> <message>"`. `validateConfig` uses a second instance with
   `useDefaults: true` and returns the defaulted object.
6. Fixtures: the files named in `ingest.md` section 7. Also `fixtures/sessions/` with one
   valid `Session` per state (8 files, `<state>.json`) used by UI tests later.
7. `contracts.lock.json`: `{"<file>": "<sha256 hex>"}` for the five schema files.
8. Tests in `test/contracts.test.ts`, titles exactly:
   - `CT-01 schema files match contracts.lock.json` (recompute SHA-256)
   - `CT-02 schemas copied from docs/contracts are byte-identical` (compare with `../../docs/contracts/*.schema.json`)
   - `CT-03 every valid ingest fixture validates`
   - `CT-04 invalid-extra-env, invalid-tool-input and invalid-version are rejected`
   - `CT-05 every session fixture validates and covers all 8 states`
   - `CT-06 validateConfig({}) returns the documented defaults` (port 47800, notifications.on.done true, restore.maximize "always", sessions.lostAfterHours 12, adapters.shell.enabled false)
   - `CT-07 validateConfig rejects an unknown key with its instancePath`
   - `CT-08 generated types are up to date` (run generate into a temp dir, compare with `src/generated`)
