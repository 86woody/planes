# T033: E2E suite (golden path, card, design, a11y)

Milestone M2 · Wave 5 · Depends on: T027, T030-T032 · Runs on: any OS

## Goal

Prove the page against the real daemon with the fake platform: sessions appear,
change state, notify, restore, acknowledge; the design tokens and the eight state
treatments are what DESIGN.md says; the page is keyboard-usable and passes axe.

## Codes against

`docs/DESIGN.md` (all), `docs/contracts/api.md` (test routes in section 3),
`attention.md` (to craft events), D-19, PRD AC-01, AC-02, AC-05, AC-06, AC-16, AC-17.

## Files

`e2e/golden-path.spec.ts`, `e2e/card.spec.ts`, `e2e/design.spec.ts`, `e2e/a11y.spec.ts`,
`e2e/support/{daemon,events,page}.ts`, `e2e/__screenshots__/**`, `docs/checkpoints/T033.md`.

## Do not touch

Everything outside `e2e/` (if the UI or daemon is wrong, stop and report with the
failing assertion; do not fix other tasks' files).

## Steps

1. `support/daemon.ts`: a Playwright worker fixture that runs `pnpm -r build` once
   (global setup), then per test file starts `node packages/daemon/dist/bin.js` with
   `MC_HOME=<tmp>`, `MC_PORT=0`, `MC_PLATFORM=fake`, `MC_TEST=1`, waits for
   `<tmp>/state/daemon.json`, reads port and token. Teardown kills it.
2. `support/events.ts`: `send(event, payload, {session, agentPid?})` POSTs an
   `IngestEnvelope` (Windows Terminal origin, increasing `sentAt`) with the bearer token;
   `fakeCalls()` reads `/api/test/fake-platform`; `setForeground(sessionId|null)`.
3. `support/page.ts`: `openPaired(page)`: `POST /api/pair-code` with the bearer token,
   `page.goto("http://127.0.0.1:<port>/")`, fill `pair-input` with the code, click
   `pair-submit`, wait for `fd-bar` and for the `banner` to be gone. CARD-04 relies on
   the session surviving the daemon restart (api.md 2): after restart the page must
   recover without the pairing banner. Restart with `MC_PORT=<the port of the first run>`
   and the same `MC_HOME`, not `MC_PORT=0`: the open page keeps reconnecting to its own
   origin's port, so a new ephemeral port would never recover.
4. Freeze time where screenshots or clocks matter with `page.clock.install({time: new Date("2026-11-08T20:41:07")})`;
   force reduced motion with `page.emulateMedia({reducedMotion: "reduce"})` for DS-08.
5. Tests, titles exactly:
   - `GP-01 SessionStart makes a T-MINUS card appear within 1 s`
   - `GP-02 UserPromptSubmit turns it ASCENT`
   - `GP-03 PermissionRequest turns it GO/NO-GO, adds a poll chip, and the fake platform records one notify`
   - `GP-04 RESTORE calls fake focus once, shows FOCUSED, and attention becomes acknowledged`
   - `GP-05 PostToolUse returns it to ASCENT and the poll strip disappears`
   - `GP-06 Stop shows NOMINAL with MECO; ACK removes MECO`
   - `GP-07 with the session set as foreground, a new PermissionRequest records no notify`
   - `GP-08 SessionEnd moves the card to SPLASHDOWN and DISMISS removes it`
   - `CARD-01 a card shows callsign, project, branch, host badge, state label, elapsed, last event and capability`
   - `CARD-02 capability none: RESTORE shows FOCUS MANUALLY and sends no focus call`
   - `CARD-03 cards sort permission, input, working, idle`
   - `CARD-04 a daemon stop shows LOS: DAEMON after 3 s and the page recovers on restart`
   - `DS-01 computed :root custom properties equal the DESIGN.md token values` (read every `--mc-*` from DESIGN.md section 1 hard-coded into the spec)
   - `DS-02 Barlow Condensed 700 and JetBrains Mono 600 are loaded` (`document.fonts.check`)
   - `DS-03 each state's rail colour equals its signal token`
   - `DS-04 unacknowledged permission card has a running steps(1) animation; acknowledged has none`
   - `DS-05 with reduced motion there are zero running animations and blinking cards get a 2px outline`
   - `DS-06 grid columns are at least 320px and cards are 196px tall`
   - `DS-07 every label element is uppercase with 0.08em letter-spacing`
   - `DS-08 fixture board screenshot matches board-<platform>.png within 1%`
   - `DS-09 empty state shows AWAITING ACQUISITION OF SIGNAL`
   - `DS-10 the page makes no request to any origin other than the daemon`
   - `AX-01 axe finds no serious or critical violations on a board with all states`
   - `AX-02 Tab reaches every RESTORE and ACK in grid order and Enter restores`
   - `AX-03 focused controls show a 2px outline`
   - `AX-04 a new permission attention is announced in the assertive live region`
6. DS-08 baseline: run once with `--update-snapshots`, commit the PNG (the
   `snapshotPathTemplate` of T001 writes `e2e/__screenshots__/board-<platform>.png`), and
   say so in the checkpoint; the orchestrator reviews it against DESIGN.md before merge
   and adds the other OSes' baselines (ORCHESTRATION.md 7).
