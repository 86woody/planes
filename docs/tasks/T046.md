# T046: Linux notifications (D-Bus)

Milestone M3 · Wave 2 · Depends on: T003 · Runs on: **Linux**

## Goal

Desktop notifications through `org.freedesktop.Notifications` with a clickable default
action, replacement by tag, withdrawal, and the daemon's own D-Bus service (used by the
KWin backend's callback).

## Codes against

`docs/platforms/linux.md` sections 3.3 (the `org.missioncontrol.Daemon` service), 5,
`platform-adapter.md` PA-07, `internal.md` section 6 (`createNotify`).

## Files

`packages/platform/src/linux/notify.ts`, `packages/platform/src/linux/dbus-service.ts`,
`packages/platform/test/linux-notify.test.ts`, `packages/platform/test/os/linux-notify.os.test.ts`,
`docs/checkpoints/T046.md`.

## Do not touch

Every other file.

## Steps

1. `dbus-service.ts`: `getDaemonService()` (singleton): on the session bus request name
   `org.missioncontrol.Daemon` and export interface `org.missioncontrol.Daemon` at `/`
   with method `Report(s)` that forwards to registered callbacks; returns
   `{onReport(cb): unsubscribe}`. No session bus -> a no-op object.
2. `notify.ts`:
   - At creation: `sessionBus()`, proxy `org.freedesktop.Notifications`
     `/org/freedesktop/Notifications`; `GetCapabilities()`; subscribe to
     `ActionInvoked` and `NotificationClosed`. Failure (`ServiceUnknown`, no bus) ->
     every `notify` returns null and `probe()` reports `linux_no_notification_server`.
   - Pure builder `notifyArgs(n, {replacesId, icon, sound, bodyMarkup})` returning the
     8 Notify arguments of linux.md 5 with dbus-next `Variant`s for hints
     (`urgency` `y` 0/1/2, `desktop-entry` `s`, `category` `s`, `suppress-sound` `b`).
   - Keep `tag -> id` and `id -> sessionId` maps; `ActionInvoked(id, "default"|"restore")`
     -> `onClick(sessionId)`; `NotificationClosed` -> delete maps.
   - `withdraw` -> `CloseNotification(id)`; `dispose` -> disconnect the bus.
3. Tests, titles exactly (unit, any OS):
   - `LU-11 notifyArgs builds app name, replaces id, actions default and restore, urgency byte and expire -1`
   - `LU-12 body is markup-escaped only when the server has body-markup`
   - `LU-13 a second notification with the same tag replaces the previous id`
   - `LU-14 no notification server: notify returns null and probe reports linux_no_notification_server`

   OS test (Linux, `MC_OS_TESTS=1`, under `dbus-run-session`), title exactly:
   - `LO-05 a test notification server receives Notify and its ActionInvoked default calls onClick with the session id`
     (the test exports its own `org.freedesktop.Notifications` with dbus-next on the private bus before creating the notifier)
