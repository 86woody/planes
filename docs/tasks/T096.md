# T096: Installed `mc` runs through npm's shim (shebang on every bin)

Milestone M5 · Wave 8h · Depends on: T087, T089 · Runs on: any OS (Windows and Linux for SK)

## Goal

`dist/mc.js` has no `#!/usr/bin/env node` first line, so npm writes a Windows shim
(`mc.cmd`) that runs `"…\dist\mc.js" %*` with no `node`. Windows then hands the file to
its `.js` association. In Windows Sandbox that is Windows Script Host, which ran it
silently and exited 0, so `mc --version`, `mc init` and `mc launch` did nothing. On
dev-pc it hung. On Linux the global `bin/mc` link has no interpreter either. SK
missed this because its `mc()` helper calls `node dist/mc.js` directly. After this task,
every bin file starts with the shebang, and SK runs `mc` through the installed shim, the
way a user does.

## Steps

1. In `scripts/package.mjs`, after esbuild writes the bundles, make every file named in the
   generated `package.json` `bin` (`dist/mc.js`, `dist/mc-hook.js`) start with exactly one
   line `#!/usr/bin/env node`. Prepend it when missing, and never write it twice: esbuild
   keeps `mc-hook.ts`'s own shebang. The shebang must be the very first line, before the
   createRequire banner.
2. In `packaging-test/package.test.mjs`, add the test
   `PK-10 every bin file in the package starts with the node shebang`. For each `bin` entry
   of the generated `package.json`, it expects the file's first line to equal
   `#!/usr/bin/env node`, and the text `#!/usr/bin/env node` to appear exactly once.
3. In `packaging-test/install.test.mjs`, change `mc(prefix, args)` to run the installed shim
   from `shimPath(prefix)`. On Windows, run it as
   `cmd.exe /d /s /c "<shim> <args>"` (Node refuses to spawn a `.cmd` without a shell). On
   Linux, run `<prefix>/bin/mc` directly. Keep the env and timeout. SK-01..SK-06 then go
   through the shim unchanged.
4. Add the test
   `SK-07 the installed mc-hook shim runs the hook and exits 0`. It runs
   `<prefix>/mc-hook.cmd` (Windows, via cmd.exe as in step 3) or `<prefix>/bin/mc-hook`
   (Linux) with argument `claude-code`, a fixture SessionStart payload on stdin, and the
   same MC_HOME. It expects exit 0 within 1500 ms.
5. Write the checkpoint. Include a direct run of the shim (`mc.cmd --version` or
   `bin/mc --version`) that prints the version.
