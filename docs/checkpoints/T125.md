# T125 checkpoint: Claude Code telemetry, AI Credits, the board on real data (D-61)

Orchestrator-built on branch `feat/telemetry-live` (2026-11-17), Woody's ask "build everything out".

## What works

- `createClaudeFold` folds a Claude Code transcript and its subagent files into `Telemetry` and span
  records. On this session's own transcript (6,966 lines, 30 subagent files) it takes 0.3 s and gives
  1,325 model calls, cache-heavy token totals, context ≈23% of a 1M window (a compaction's
  `preTokens` of 580,635 proves the 1M window), Bash 501 runs / 20 failed, PowerShell 351 / 28,
  20 subagent rows, 3 compactions and 79 runs (78 closed by `turn_duration`, the current one open).
- The daemon reads `claude-code` sessions' transcripts (new lines only, read-only, path from
  `CLAUDE_CONFIG_DIR`, else `<MC_HOME>/claude`, else `~/.claude`) and feeds the spans to the trace
  store, so the session page and the run trace work for Claude Code.
- AI Credits = nano-AIU / 1e9 (Copilot CLI 1.0.112 `NANO_AIU_PER_AIU`), per session and per day.
- The four board cards, the header credits pill and the Needs you line read real values only; the
  sample generator is gone.

## What does not

- Codex has no reader. A `copilot -p` run sends no session hook, so its OTel spans are dropped.
- Permission wait time is not in a Claude Code transcript (`permissions.waitedMs` stays 0).
- The context window is an estimate (200k or 1M), shown with `≈`.

## What surprised

- Claude Code writes one transcript line per content block, each with the full usage of the message:
  counting per line would have multiplied tokens by the block count.
- On dev-pc only two sessions (both Copilot CLI) had telemetry; every Claude Code session,
  most of the board, had none before this.
- The shell integration's OTel file works: one `copilot -p` prompt wrote `shell-<pid>.jsonl` with an
  `invoke_agent` span and 4 metrics. The VS Code OTel settings are right but VS Code (running since
  2026-11-11) has not reloaded since they were set, so it has written nothing.
