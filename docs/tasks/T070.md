# T070: Copilot CLI adapter

Milestone M4 · Wave 7 · Depends on: T051 · Runs on: any OS

## Goal

GitHub Copilot CLI sessions appear as cards the way Claude Code and Codex do. This task
builds and unit-tests the adapter; a later task proves it with a real Copilot run.

injected env. Nothing reads Copilot credentials, logs or its session store.
