# T122: the run trace page: one agent run as a waterfall (D-58)

Milestone M5 · Wave 10b · Depends on: T119 · Runs on: any OS

## Goal

and errors.

## Steps

1. `trace-layout.ts`, pure, no DOM:
   ```ts
   export interface TraceRow { span: TraceSpan; depth: number; orphan: boolean; open: boolean;
     startMs: number; endMs: number; leftPct: number; widthPct: number }
   export interface TraceLayout { t0: number; t1: number; totalMs: number; rows: TraceRow[];
     ticks: { pct: number; label: string }[] }
   export function layoutRun(run: TraceRun, now: number): TraceLayout
   ```
   - `startMs` = `Date.parse(span.startedAt)`; `open` = `durationMs === null`; `endMs` = start +
     duration, or `max(start, now)` when open.
   - `t0` = min start over spans (or `Date.parse(run.startedAt)` with no spans); `t1` = max end, at
     least `t0 + 1`; `totalMs` = `t1 - t0`.
   - Order: the root (kind `agent`, `parentSpanId` null or not in the run) first, then depth-first;
     children of a span sorted by start, ties by `spanId`. Every span whose parent is not in the run
     and that is not the root comes after the tree, at depth 0, `orphan: true`, in start order, with its
     own children under it. A cycle never loops (each span appears once).
   - `leftPct` = 100 * (start - t0) / totalMs; `widthPct` = 100 * (end - start) / totalMs.
   - `ticks`: 0, 25, 50, 75, 100 % with `durationText(totalMs * pct / 100)` (`0 ms` for 0).
2. `RunTrace.tsx`:
   ```ts
   export function RunTrace(p: { session: Session; run: TraceRun | null; loading: boolean;
     now: number }): JSX.Element
   ```
   Root `<section className="pagev" data-testid="run-view" aria-labelledby="rv-h">`. `run` null and
   not loading -> the `rv-missing` text and the back link only; loading -> `Loading run…`. Otherwise the
   head, the notes, the waterfall and the span detail exactly as DESIGN.md 3a says. `rv-back` is
   `<a href={routeHref({ page: "session", id: session.id })}>← {callsign}</a>`.
3. The waterfall is a `<div role="grid" data-testid="rv-waterfall">` of `<div role="row" tabIndex={0}
   data-testid="rv-row" data-kind data-status data-depth data-orphan? data-open? aria-selected>` rows.
   Bars are absolutely positioned inside the track by `left: <leftPct>%` and `width: max(2px,
   <widthPct>%)`. Each span event is an `<i className="ev" title="<name> +<offset>">` at its offset
   inside the bar. Click or Enter selects the row (state in the component); the `rv-span` panel shows
   the fields listed in DESIGN.md (start offset is `durationText(startMs - t0)`).
4. `trace.css`: grid of 300px label, track `minmax(0, 1fr)`, 140px right column; under 760px label above
   track and the right column hidden; kind tag box like the adapter badge (Geist Mono 10px, 1px
   `--hair2`); bar colours per DESIGN.md; `[data-open] .bar` right edge dashed; error rows `--look`;
   axis ticks Geist Mono 11px `--ink3`; the selected row `--card2` background. Tokens only.
   Import it from `RunTrace.tsx`. (`.pagev` itself is styled by T121; do not redefine it.)

## Tests

`packages/ui/test/trace-layout.test.tsx`:
- `RT-01` a root with two chat spans and a tool span nested under the second chat: order root, chat1,
  chat2, tool; depths 0, 1, 1, 2; percentages from the times (a 10 s run, a span at +2.5 s for 1 s ->
  left 25, width 10); ticks labelled `0 ms`, `2.5 s`, `5.0 s`, `7.5 s`, `10.0 s`.
- `RT-02` an incomplete run (no root, spans whose parent is missing) lays out every span as an orphan at
  depth 0 in start order; an open span ends at `now`; a parent cycle (a -> b -> a) still yields each span
  once.

`packages/ui/test/run-trace.test.tsx`:
- `RT-03` renders one `rv-row` per span with `data-kind` and `data-depth`, the kind tags `AG CH TL`, the
  chat row's right column `in 1,200 · out 300`, an errored tool row with `data-status="error"` and the
  word `Error`.
- `RT-04` `complete: false` shows `rv-open`; `droppedSpans: 12` shows `rv-dropped` with
  `12 spans past the 500-span limit are not shown.`; `run` null shows `rv-missing` and a back link to
  `#/s/<id>`.
- `RT-05` clicking a row sets `aria-selected="true"` and `rv-span` lists its model, tokens, TTFT and its
  events; Enter on another row moves the selection.
