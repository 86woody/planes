# T094: Tests that start a daemon stop it before deleting its MC_HOME

Milestone M5 · Wave 8g · Depends on: T085, T092 · Runs on: any OS

## Goal

PC-13 (`package-cli.test.ts`) and IN-10..IN-12 (`init-launch.test.ts`) start real daemons
with a temp `MC_HOME`. Both files' `afterEach` delete the temp dirs first and call
`mc stop` second, so `stop` finds no `daemon.json` and the daemon keeps running. Every run
leaked daemons: 18 were found on dev-pc on 2026-11-15. After this task, every daemon a
test starts is gone when the file finishes, and a test proves it.

## Codes against

`AGENTS.md` "Test hygiene", `docs/contracts/config.md` 1-2 (`daemon.json`).

## Files

`packages/cli/test/package-cli.test.ts`, `packages/cli/test/init-launch.test.ts`,
`docs/checkpoints/T094.md`.

## Do not touch

Product code. Every other test's title, ID and assertions. Change only the cleanup code
and add the two LK tests.

## Steps

1. In both files, rewrite `afterEach` so that it first stops the daemon and only then
   deletes the temp dirs.
   - When `daemonEnv` is set: read `daemon.json` through `resolveCliPaths(daemonEnv)` and
     `readDaemonFile` (as `package-cli.test.ts` already does), and push the pid into a
     module-level `startedPids: number[]`.
   - Then run `main(["stop"], ...)`. If the process is still alive afterwards
     (`isAlive(pid)`), `process.kill(pid, "SIGKILL")` it.
   - Then remove the sandboxes and dirs. `init-launch.test.ts` gets the same
     `readDaemonFile`, `isAlive` and SIGKILL fallback. Import them from the same modules
     `package-cli.test.ts` uses.
2. In `package-cli.test.ts`, add a last test titled exactly
   `LK-01 no daemon started by this file is still running`. It expects
   `startedPids.length` to be at least 1, then waits up to 2 s, polling every 100 ms with
   no sleep longer than that, for every pid to stop being alive, and expects `isAlive` to
   be false for each.
3. In `init-launch.test.ts`, add a last test titled exactly
   `LK-02 no daemon started by this file is still running`, with the same shape as LK-01.
4. Run `pnpm -r build && pnpm task:check T094`. Then, in PowerShell, list `node.exe`
   processes whose command line contains this worktree's `packages\daemon\distin.js`.
   Record that the list is empty in the checkpoint.
