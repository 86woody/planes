# T011: Notify policy and coalescer

Milestone M1 · Wave 1 · Depends on: M0 · Runs on: any OS

## Goal

Implement `decide`, `decideRenotify` and `Coalescer` in `@mc/core`: given a session
change, decide whether an OS notification is sent and what it says.

## Codes against

`docs/contracts/attention.md` section 6 (normative), `DESIGN.md` section 4 (labels),
`config.schema.json` (`notifications`), `api.schema.json` `$defs.OsNotification`.

## Files

`packages/core/src/notify-policy.ts`, `packages/core/test/notify-policy.test.ts`,
`docs/checkpoints/T011.md`.

## Do not touch

Every other file. Build test sessions inline in your test file from
`packages/contracts/fixtures/sessions/*.json` (read with `fs`), do not import T010's helpers.

## Steps

1. Export `NotifyContext`, `NotifyDecision`, `decide`, `decideRenotify`, `Coalescer`
   with the shapes in section 6. `localMinutes` is supplied by the caller (pure function).
2. Label map (DESIGN.md 4): permission -> `GO/NO-GO`, input -> `HOLD`, error ->
   `ANOMALY`, done -> `NOMINAL`.
3. `Coalescer`: `offer(n: OsNotification, now: number): OsNotification[]` returns the
   notifications to send immediately (at most 3 per rolling 5000 ms window; the rest
   are held); `flush(now): OsNotification[]` returns the summary when a window with held
   items has closed (`now >= windowStart + 5000`), at most one summary per window.
   Urgency order `critical > normal > low`.
4. Truncation by code points (`Array.from(s).slice(0, n).join("")`).
5. Tests titled exactly `NP-01 ...` to `NP-14 ...`, one per row of 6.1-6.3. NP-09 covers
   a wrapping window (`22:00-07:00`) at 23:30 (suppressed), 06:59 (suppressed), 07:00
   (not), and permission during quiet hours (sent). NP-12 offers 5 notifications at
   t=0..4 ms: 3 returned, `flush(4999)` empty, `flush(5000)` one summary with body
   `"2 sessions need attention"`.
