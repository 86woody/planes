# T044: macOS notifications

Milestone M3 · Wave 2 · Depends on: T003 · Runs on: **macOS** if available, else any OS

## Goal

Notifications on macOS through alerter (in-process clicks), terminal-notifier (click runs
`mc restore`), or osascript (no click), with backend detection.

## Codes against

`docs/platforms/macos.md` section 4 (normative), `platform-adapter.md` PA-07,
`internal.md` section 6 (`createNotify`), `api.schema.json` `OsNotification`.

## Files

`packages/platform/src/macos/notify.ts`, `packages/platform/src/macos/scripts/notify-osascript.applescript`,
`packages/platform/test/macos-notify.test.ts`, `packages/platform/test/os/macos-notify.os.test.ts`,
`docs/checkpoints/T044.md`.

## Do not touch

Every other file.

## Steps

1. Backend detection at creation: `which("alerter")`, `which("terminal-notifier")`,
   else osascript. Expose `backend` on the returned object for tests.
2. Pure argument builders: `alerterArgs(n)`, `terminalNotifierArgs(n, {node, mcJs})`,
   `osascriptArgs(n)` exactly per macos.md 4 (`-group` = notification `tag`;
   `-execute` command uses the absolute `process.execPath` and
   `<repoRoot>/packages/cli/dist/mc.js`, each single-quoted with `'` escaped as `'\''`).
3. alerter: spawn (not `exec`: it stays alive), parse its stdout JSON on exit;
   `activationType` `contentsClicked`/`actionClicked` -> `onClick(n.sessionId)`. Keep at
   most 10 live; kill the oldest beyond. `notify` resolves as soon as the process is
   spawned (PA-07).
4. `withdraw`: alerter kill + `alerter -remove <tag>`; terminal-notifier `-remove <tag>`;
   osascript no-op.
5. `probe()`: `notify: true` always on macOS; `notifyClick: backend !== "osascript"`;
   issue `macos_notify_no_click` (info, fix "brew install vjeantet/tap/alerter") for osascript.
6. Tests, titles exactly (unit, any OS):
   - `MU-09 alerterArgs has -title -message -group -actions RESTORE -timeout 600 -json`
   - `MU-10 terminalNotifierArgs -execute quotes paths with spaces and single quotes`
   - `MU-11 alerter JSON contentsClicked calls onClick with the session id; timeout does not`
   - `MU-12 probe reports notifyClick false and the info issue for the osascript backend`

   OS test (macOS, `MC_OS_TESTS=1`), title exactly:
   - `MO-05 notify through the osascript backend returns a handle and does not throw`
