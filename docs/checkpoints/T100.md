# T100 checkpoint: the Terrain deck board (D-48)

Branch `task/T100-terrain-ui`, built on `integration` at a81414e. Host dev-pc.

## What works

- **The deck** (`packages/ui`): header (brand, host, Link and Notify lamps, HH:MM clock,
  List / Telemetry / theme / ? buttons), readiness card with the R popover, the Needs you
  stack (max three cards, "+N more in the list", a menu for Acknowledge / Dismiss alert /
  Details / Copy cwd), the Fleet terrain hero, the list view (L) with ended and lost
  grouped and collapsible, the details sheet (I), the keys sheet (?), four telemetry
  cards that read "Not wired" with a dashed skeleton and a T preview on labelled sample
  data, light and dark themes (dark default, `prefers-color-scheme: light`, a stored
  toggle), toasts.
- **Data**: `store.ts` and `api.ts` unchanged except the old global R shortcut is gone
  (R is readiness now). Regions are distinct `project` values. Activity is kept client
  side in `activity.ts` (recency of `lastEvent.at` and the rate of
  `lastEvent.at`/`updatedAt` changes), no contract change.
- **Terrain** (`terrain.ts`, a typed port of the concept's canvas code): HiDPI,
  ResizeObserver, colours from `--c-*` tokens (re-read on theme change), back-to-front
  scan lines with paper-filled occlusion, pads per project, peaks per session, orange
  ridged peaks and glow for needs-you and error, green-dotted crests for working,
  callout pills with collision-avoiding placement, the selected card with a leader, the
  dock of the latest events. Pointer Events with capture, `touch-action: none`, inertia,
  clamped pitch/zoom/pan, shift/right-drag pan, wheel and pinch zoom, double-click and
  Reset, still click selects. Reduced motion: no inertia, flights, pulses or wobble; the
  map redraws only on change; unacknowledged Needs you cards keep a 2px outline.
- **Kept behaviour**: pairing banner (`pair-input`, `pair-submit`, `pair-error`), the
  daemon-down banner after 3 s with recovery, config banner, Restore including
  capability none (copies the cwd, "Focus manually · cwd copied", no focus call), results
  for 5 s, Acknowledge, Dismiss (DELETE for ended/lost; a client-side "dismiss alert" for
  live attention, since the API refuses DELETE on live sessions), copy cwd, the highlight
  message (selects and marks the session), the assertive/polite announcer.
- **Plain words** in `notify-policy.ts` titles ("MC-03 · Needs permission · project") and
  in `mc status` (`stateWord()`; "Done" for idle with done attention). The coalesced
  summary title stays "MISSION CONTROL" because `packages/daemon/test/notifier.test.ts`
  and `ws.test.ts` (not mine) assert it.
- **Tests**: every kept id rewritten (UC-01..12, UB-01..07, US-09, DS-01..10, CARD-01..04,
  GP-01..08, AX-01..04; SYS-* untouched and still green). New TR-01 (drag orbits, no page
  scroll, wheel zooms, reset), TR-02 (still click selects, empty click deselects), TR-03
  (list holds every session, ended/lost collapsible, "+N more" opens it), TR-04 (keyboard
  map), registered in `scripts/test-ids.json` as T100/m5 in `e2e/design.spec.ts` (the
  gate's e2e stage only runs the four existing spec files, and `gates.json` is frozen).
  AX-01 runs axe on the deck and the list in both themes. DS-10 also asserts no console
  errors besides the browser's log of the pre-pairing 401.
- **Screenshots**: `e2e/__screenshots__/board-win32.png` and `board-linux.png`
  regenerated (dark, 1440x900, the longest wait selected with N, three pills).

## Decided on my own

- **Which element is a "card" in tests**: list-view rows carry `data-testid="card"` (every
  session lives there); Needs you cards are `needs-card`. E2E opens the list (`openList`)
  where it needs every session.
- **Contrast over the concept**: `--ink3` dark #706b62 → #8f897f, light #827e74 → #6b675e;
  light `--go` #1d744a → #1a6a43, `--look` #b34d0b → #9c4209 (canvas `--c-look` keeps
  #b34d0b). Needed for axe 4.5:1 on cards, pills and hovered rows. Slightly brighter
  secondary text than the concept; the look is otherwise unchanged.
- Header shows the hostname where the concept said "Terrain deck"; the clock is HH:MM.
- Lamps: only Link and Notify (requirement 2); Focus and Cfg moved out (focus capability
  shows as Restore-capable in readiness details, config errors as the banner). UB-03 now
  tests the Notify lamp.
- Readiness details row "Daemon link" replaces the concept's "Machines reachable" (one
  daemon per machine, PRD 5).
- `vite.config.ts` `assetsInlineLimit: 0`: Vite had inlined small font subsets as
  `data:` URLs, which the daemon's CSP blocks (console errors).
- `fixText(tab_not_addressable)` drops "(TAB: MANUAL)".

## Surprises

- `--update-snapshots` (default "changed") does not rewrite a baseline that still matches
  within 1%; a missing set of pills fit inside the tolerance. DS-08 now asserts the three
  visible pills before the screenshot, and baselines were written with `=all`.
- Pills measured while the list view hid them were cached at width 0 and never shown;
  the engine no longer caches a zero size.
- `packages/contracts/src/generated/session.ts` (frozen) still documents the old mission
  labels in a comment on `State`. Not a blocker; worth a contract-docs touch later.
