# T041: Windows focus, foreground, WT tabs

Milestone M3 · Wave 2 · Depends on: T003 · Runs on: **Windows**

## Goal

Bring a window to the foreground and maximize it despite the Windows foreground lock,
verify it, fall back to flashing, and select the right Windows Terminal tab.

## Codes against

`docs/platforms/windows.md` sections 3, 4 (normative), `platform-adapter.md` PA-01..PA-06,
`internal.md` section 6 (`createFocus`, `Discover`), `session.schema.json` `FocusResult`.

## Files

`packages/platform/src/windows/focus.ts`, `packages/platform/src/windows/ps/wt-tabs.ps1`,
`packages/platform/src/windows/ps/wt-select-tab.ps1`,
`packages/platform/test/windows-focus.test.ts`,
`packages/platform/test/os/windows-focus.os.test.ts`, `docs/checkpoints/T041.md`.

## Do not touch

`win32.ts` (declare the extra user32 functions you need locally in `focus.ts`:
`ShowWindow`, `SetForegroundWindow`, `BringWindowToTop`, `SendInput` with the `INPUT`
union struct (type, ki: {wVk, wScan, dwFlags, time, dwExtraInfo}) sized for x64,
`AttachThreadInput`, `GetCurrentThreadId`, `FlashWindowEx` with `FLASHWINFO`,
`AllowSetForegroundWindow`, `IsIconic`, `IsZoomed`, `IsWindow`, `GetForegroundWindow`,
`GetWindowThreadProcessId`), `discover.ts`, `notify.ts`.

## Steps

1. Split pure from impure: `planFocus(state: {isWindow, isIconic, elevated}, opts) -> Step[]`
   (pure: the ordered list of windows.md 3 steps with their ShowWindow constants) and
   `runFocus(steps, user32)` (impure). `chooseTab(tabs) -> index | null` (pure, windows.md
   4.2 rules a and b exactly).
2. `focus(target, opts)`: windows.md 3 steps 1-9 exactly, with the 25 ms/300 ms polling
   and the strategies. Every call path returns a `FocusResult` (PA-01).
3. `wt-tabs.ps1 <hwnd-decimal>`: load `UIAutomationClient` and `UIAutomationTypes`;
   `[System.Windows.Automation.AutomationElement]::FromHandle([IntPtr]<hwnd>)`;
   `FindAll(Descendants, ControlType=TabItem)`; output JSON
   `[{"index":0,"name":"...","selected":true}]`. `wt-select-tab.ps1 <hwnd> <index>`:
   same lookup, `GetCurrentPattern(SelectionItemPattern.Pattern).Select()`; output
   `{"ok":true}`. Both run through `exec("powershell.exe", ["-NoProfile","-NonInteractive","-ExecutionPolicy","Bypass","-File", <path>, ...])`.
4. Tests, titles exactly (unit, any OS):
   - `WU-07 planFocus always: maximize, alt-key, foreground, verify`
   - `WU-08 planFocus if-minimized on a non-minimized window: SW_SHOW only`
   - `WU-09 planFocus never on a minimized window: SW_RESTORE`
   - `WU-10 planFocus on a missing window: not_found; on an elevated window: permission_denied`
   - `WU-11 chooseTab: one tab -> 0; one claude glyph tab among three -> its index; two -> null`
   - `WU-12 focus result mapping: verified -> focused, tab failure -> focused_window_only, verify fails twice -> flashed`

   OS tests (Windows, `MC_OS_TESTS=1`), titles exactly:
   - `WO-02 minimized conhost window: focus(always) -> focused, zoomed, foreground`
   - `WO-03 focus(never) on a minimized window: foreground, not zoomed`
   - `WO-04 closed window: not_found`
   - `WO-07 Windows Terminal window with one tab: focused` (if `wt.exe` is not on PATH, the test asserts `which("wt.exe") === null` and passes with that as its only assertion; record it in the checkpoint)
