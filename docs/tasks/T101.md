# T101: installer commands that are not `.exe` run on Windows (cmd.exe quoting)

Milestone M5 · Wave 8i · Depends on: T083 · Runs on: windows

## Goal

On Windows `realRun` sends every command that is not an `.exe` (`code.cmd`, `pnpm.cmd`,
`pwsh`) through `cmd.exe /d /s /c "<line>"`. Node quotes that last argument again
(`"\"<line>\""`), so cmd.exe cannot parse it and the command never runs. Measured on
dev-pc 2026-11-16 (W-04 setup): `mc install vscode` failed with
`'\"pnpm --dir ... build\"' is not recognized`, and the same path breaks `code
--install-extension`, so `mc init` in 1.0.0 cannot install the VS Code extension on
Windows. The installer tests inject a fake `run`, so no test reached `realRun`.

## Steps

1. `exec` accepts `windowsVerbatimArguments` and passes it to `spawn` (default false).
2. `realRun` passes `windowsVerbatimArguments: true` with its `cmd.exe /d /s /c` call.
3. Test `RR-01 a .cmd in a path with a space runs and receives a quoted argument intact`
   (Windows only): a `.cmd` in a directory whose name has a space, run through `realRun`
   with the argument `hello world`, prints it intact and exits 0.
