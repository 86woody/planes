# T012: Host classification and callsigns

Milestone M1 · Wave 1 · Depends on: M0 · Runs on: any OS

## Goal

Implement `classifyHost(origin)` (the rule table that says whether a session lives in
VS Code, Windows Terminal, iTerm2, ...) and the `CallsignAllocator`.

## Codes against

`docs/contracts/ingest.md` section 5 (normative), `session.schema.json` `$defs.Host`,
D-20 in `docs/DECISIONS.md` (callsigns), `internal.md` section 4.

## Files

`packages/core/src/classify.ts`, `packages/core/src/callsign.ts`,
`packages/core/test/classify.test.ts`, `docs/checkpoints/T012.md`.

## Do not touch

Every other file.

## Steps

1. `classifyHost(origin: IngestOrigin): Host`. Implement rules 1-11 in order, the three
   name lists as exported `const` arrays (`VSCODE_NAMES`, `SHELL_NAMES`,
   `LINUX_TERMINALS`), `multiplexer` and `display` per the bullets. Name normalisation:
   lower-case, strip a trailing `.exe`. "Between the agent and that VS Code process" in
   rule 2 means: ancestry entries whose index is greater than the agent entry's index and
   lower than the VS Code entry's index (ancestry is nearest-first, starting at the
   hook's parent, so the shell Claude Code uses to run the hook sits *below* the agent
   and does not count). If `origin.agent` is null, rule 2's ancestry clause never matches.
2. `CallsignAllocator(counter, inUse)`: `next()` increments the counter (1..99, then
   wraps to 1) and returns `MC-<2 digits>`, skipping values in `inUse()`; if all 99 are
   in use it returns the next value anyway. `counter()` returns the current counter for
   persistence.
3. Tests titled exactly:
   - `CL-01 SSH_CONNECTION -> remote`
   - `CL-02 CLAUDE_CODE_ENTRYPOINT claude-vscode -> vscode-extension`
   - `CL-03 Code.exe ancestor with no shell between -> vscode-extension`
   - `CL-04 TERM_PROGRAM vscode with pwsh between -> vscode-terminal`
   - `CL-05 WT_SESSION -> windows-terminal, app WindowsTerminal.exe`
   - `CL-06 windows with consoleHwnd and no WT -> conhost`
   - `CL-07 Apple_Terminal -> macos-terminal`
   - `CL-08 ITERM_SESSION_ID -> iterm2`
   - `CL-09 WEZTERM_PANE -> wezterm`
   - `CL-10 KITTY_WINDOW_ID -> kitty`
   - `CL-11 linux ancestry gnome-terminal-server -> linux-terminal with app name`
   - `CL-12 nothing matches -> unknown`
   - `CL-13 TMUX + TMUX_PANE -> multiplexer tmux %3, kind unchanged`
   - `CL-14 display: WAYLAND_DISPLAY beats DISPLAY; windows -> win32; macos -> cocoa`
   - `CL-15 callsigns run MC-01..MC-99 then wrap and skip in-use values`
   - `CL-16 every classifyHost result validates as session.schema.json Host`
