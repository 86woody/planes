# T025: Liveness and git info

Milestone M1 · Wave 2 · Depends on: T003 · Runs on: any OS

## Goal

Detect agent processes that died without `SessionEnd`, time out sessions with no PID,
and read project name and branch from git.

## Codes against

`ARCHITECTURE.md` section 6, `attention.md` SM-21/SM-22, `config.schema.json`
(`sessions.livenessIntervalSeconds`, `lostAfterHours`), `internal.md` (`Liveness`,
`createLiveness`, `readGit`), `platform-adapter.md` PA-09.

`packages/daemon/src/liveness.ts`, `packages/daemon/src/git.ts`,

Everything else.

## Steps

1. `createLiveness(deps)`: `start()` sets an interval of
   `livenessIntervalSeconds * 1000` calling `checkNow()`; `stop()` clears it.
   `checkNow()`: for each record whose state is not ended/lost:
   - `agentPid` set: `platform.processAlive(pid, record.origin?.agent?.startTime ?? null)`;
     false -> `sessions.apply({kind: "process_exited", sessionId, at: clock.now()})`.
   - `agentPid` null and `clock.now() - Date.parse(updatedAt) > lostAfterHours * 3600000`
     -> `apply({kind: "lost_timeout", ...})`.
   Checks run sequentially; one failing check (rejection) is logged, not fatal.
2. `readGit(cwd)`: `execFile("git", ["-C", cwd, "rev-parse", "--show-toplevel", "--abbrev-ref", "HEAD"], {timeout: 2000})`;
   success -> `project = basename(line 1)`, `branch = line 2` (`HEAD` -> null);
   a repo with no commits makes the command exit 128: then retry once with
   `git -C <cwd> rev-parse --show-toplevel` + `git -C <cwd> symbolic-ref --short HEAD`;
   failure (not a repo, git missing, timeout) -> `{project: basename(cwd), branch: null}`.
   Cache results by cwd for 30 s.
3. Tests, titles exactly:
   - `LV-01 a dead pid produces process_exited within one interval` (fake timers, FakePlatform `alivePids` without the pid)
   - `LV-02 a pid alive with a different start time counts as dead`
   - `LV-03 no pid and no event for lostAfterHours produces lost_timeout`
   - `LV-04 ended sessions are not checked`
   - `GI-01 readGit in a temp git repo on branch mc-test returns the repo basename and mc-test` (in a temp dir: `git init -b mc-test`, then `git -c user.name=t -c user.email=t@t commit --allow-empty -m init`; without a commit `rev-parse --abbrev-ref HEAD` exits 128 and the test would see the not-a-repo fallback; requires git on PATH, which the toolchain stage guarantees)
   - `GI-02 readGit outside a repo returns basename(cwd) and null`
   - `GI-03 readGit caches by cwd for 30 s`
