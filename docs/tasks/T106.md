# T106: larger fleets keep the rolling ground; telemetry row only with the T preview (D-52)

Milestone M5 · Wave 8i · Depends on: T105 · Runs on: any OS

## Goal

Woody (2026-11-16): the live map looked lower quality than the 3C concept, and the telemetry
row should be hidden until a data source exists. With 10 to 15 project pads the layout
filled the 400-unit world with narrow gaps and the base relief (flat on pads, about 70 units
to rise) never rolled, so the scan lines ran straight.

`docs/DECISIONS.md` D-52, `docs/DESIGN.md` 3 (Telemetry) and 5 (Relief).

## Steps

1. `layoutRegions`: more than four pads pack into 560 x 400 units; four or fewer unchanged.
2. `reliefRise(regions)`: 70 up to four pads, else 90% of the narrowest pad gap, 14 to 70;
   the relief ramp uses it.
3. The telemetry row renders only while the T preview is on.
4. Tests `TV-04`, `TV-05`; DS-06 checks no row by default and the four cards under T;
   regenerate the board snapshots on Windows and Linux.
