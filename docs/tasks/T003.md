# T003: `@mc/platform` types, exec, fake, conformance, selection

Milestone M0 · Wave 0d · Depends on: T002 · Runs on: any OS

## Goal

Freeze the platform interface as code, give everyone a scriptable `FakePlatform`, a
reusable conformance suite, the child-process helper, and `createPlatform()`.

## Codes against

`docs/contracts/platform-adapter.md` (all), `docs/contracts/internal.md` section 6
(`exec.ts`, `PlatformEnv`), `api.md` section 3 (`/api/test/fake-platform` uses `FakeCall`).

## Files (create or replace stubs)

`packages/platform/src/types.ts`, `src/exec.ts`, `src/index.ts`, `src/null.ts`,
`src/fake/index.ts`, `test/conformance.ts`, `test/fake.test.ts`, `docs/checkpoints/T003.md`.

## Do not touch

`packages/platform/src/{windows,macos,linux,process}/**` (stubs stay), other packages.

## Steps

1. `types.ts`: the interface block of `platform-adapter.md` section 1 verbatim, plus
   `PlatformEnv` and `FakeCall`/`FakeScript` types from section 5. `RestoreReason`,
   `Host`, `FocusResult`, `Capabilities`, `OsNotification`, `IngestOrigin`, `Config` are
   imported from `@mc/contracts`.
2. `exec.ts`: `exec` with `child_process.spawn(file, args, {shell: false, windowsHide: true, env})`,
   collect stdout/stderr as UTF-8, `timeoutMs` default 3000: on timeout kill the process
   (`SIGKILL`; on Windows `taskkill /pid <pid> /T /F`) and resolve
   `{code: null, timedOut: true}`; never reject (spawn error -> `{code: null, stderr: err.message}`).
   `which` uses `where` on Windows, `command -v` via `/bin/sh -c` elsewhere.
   `semaphore` limits concurrent `run` calls to 4.
3. `null.ts`: `NullPlatform` per section 2 (focus -> `failed/unsupported`, notify -> null,
   capabilities `{focus: "none", notify: false, notifyClick: false, issues: [{code: "platform_unsupported", ...}]}`).
4. `fake/index.ts`: `FakePlatform` per section 5. Defaults: `resolveTarget` ->
   `{window: {os: <origin.os>, handle: "0xFAKE" + (origin.agent?.pid ?? 0), pid: origin.agent?.pid ?? 0, app: "FakeTerm", title: "fake"}, inner: null, capability: "full", reason: null}`;
   `focus` -> result with `focusResult` code (status derived per session.schema.json
   rule), `detail: "fake"`, `at` = ISO of `Date.now()`; `foregroundWindow` -> window
   with handle `foregroundSessionWindow` or null; `deadHandles` -> `windowExists` false
   and `focus` `{failed, not_found}` for those handles; `processAlive(pid, st)` -> false
   if `pid` is not in `alivePids` (unless `"all"`) or `startTimes[pid]` is set and `!== st`; `notify` returns `{id: "fake-<n>"}` and
   stores `onClick` so tests can call `fake.click(sessionId)`; every method appends a
   `FakeCall` and calls `log`. `delayMs` delays each method.
5. `index.ts`: `createPlatform(env: PlatformEnv)` per section 2 using dynamic
   `import("./windows/index.js")` etc. (so koffi loads only on Windows). Re-export types,
   `FakePlatform`, `NullPlatform`, `exec`, `which`.
6. `test/conformance.ts` exports
   `checkConformance(make, fixtures): Promise<{rule: string; ok: boolean; detail: string}[]>`
   (a plain function running the PA-01, PA-02, PA-04, PA-07, PA-09 checks; PA-05 is not
   in the generic suite, see platform-adapter.md 3) and
   `runConformance(name, make, fixtures)` which registers one Vitest test per rule titled
   `conformance: <rule> <description>` (the `conformance:` prefix keeps these titles out
   of the ID audit, which only matches titles starting with an ID).
   `ConformanceFixtures = { origin: IngestOrigin; host: Host; deadWindow: NativeWindow; deadPid: number }`.
7. `test/fake.test.ts`, titles exactly:
   - `FK-01 createPlatform returns FakePlatform when MC_PLATFORM=fake`
   - `FK-02 fake records every call with method and args`
   - `FK-03 fake focus returns the scripted code with the matching status`
   - `FK-04 fake click invokes the stored onClick with the session id`
   - `FK-05 fake foregroundWindow follows setScript`
   - `FK-06 exec resolves timedOut and kills a process that outlives timeoutMs` (spawn `node -e "setTimeout(()=>{},10000)"` with 200 ms)
   - `FK-07 NullPlatform focus returns failed/unsupported`
   - `FK-08 fake passes the conformance checks` (`checkConformance` on a fake whose
     `alivePids` excludes `deadPid` and whose `deadHandles` contains `deadWindow.handle`;
     assert every entry `ok`)
