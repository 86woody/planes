## Steps

1. `telemetry-format.ts`, exactly these exports (`Session`, `Telemetry` from `@mc/contracts`):
   - `type Availability = "data" | "pending" | "na" | "none"`.
   - `availability(s: Session): Availability`: `s.telemetry` non-null -> `data`; else adapter
     `copilot-cli` -> `pending`, `shell` -> `na`, any other -> `none`.
   - `availabilityText(a: Exclude<Availability, "data">): string`: pending `No data yet`, na `n/a`,
     none `No data`.
   - `compact(n: number): string`: under 1,000 the integer with en-US grouping (`Math.round`); under 1e6
     `12.3k`; under 1e9 `4.56M`; else `1.23B`. Three significant digits for k/M/B, trailing zeros kept
     as `toPrecision(3)` gives them (`1.00k`). Negative or non-finite -> `0`.
   - `credits(t: Telemetry): { text: string; unit: string }`: `aiCredits` non-null -> `toFixed(2)` and
     `AI Credits`; else `nanoAiu` non-null -> `compact(nanoAiu)` and `nano-AIU`; else `—` and ``.
   - `rateText(n: number): string`: `Math.round(n)` with en-US grouping.
   - `contextPct(t: Telemetry): number | null` = `t.context.estimatePct`; `contextText(t)`: null -> `—`,
     else `≈` + `Math.round(pct)` + `%`; `contextOver(t)`: pct > 85.
   - `durationText(ms: number | null): string`: null or negative -> `—`; under 1,000 `430 ms`; under
     60,000 one decimal `4.2 s`; under 3,600,000 `3m 05s`; else `1h 02m`.
   - `waitedMs(t)`: `t.permissions.waitedMs + t.input.waitedMs`.
   - `failedTools(t)`: sum of `t.tools[].failed`.
   - `errorRatePct(t)`: `t.calls.total === 0` -> null, else `100 * failed / total`.
   - `ageText(iso: string, now: number): string` = `format.age(now - Date.parse(iso))` + ` ago`.
   - `type SortKey = "credits" | "rate" | "ctx" | "waited" | "failed"` and
     `sortValue(s: Session, k: SortKey): number | null`: null when `s.telemetry` is null; credits uses
     `aiCredits ?? nanoAiu ?? null`; rate `tokenRate`; ctx `contextPct`; waited `waitedMs`; failed
     `failedTools`.
2. `route.ts`:
   - `type Route = { page: "deck" } | { page: "session"; id: string } | { page: "run"; id: string; traceId: string }`.
   - `parseRoute(hash: string): Route`: strip a leading `#`; `/s/<a>` -> session, `/s/<a>/run/<b>` -> run,
     segments through `decodeURIComponent` (a decode error -> deck); anything else -> deck.
   - `routeHref(r: Route): string`: `#/`, `#/s/<encodeURIComponent(id)>`, `#/s/<id>/run/<encodeURIComponent(traceId)>`.
     `parseRoute(routeHref(r))` equals `r` for any id, including ids with `/`, `#`, `%` and spaces.
   - `useRoute(): [Route, (r: Route) => void]`: a React hook on `hashchange`; the setter assigns
     `location.hash` (so Back works).
3. `api.ts`: add `traces(id: string): Promise<TracesResponse | number>` to the `api` object and its type:
   `GET /api/sessions/<encodeURIComponent(id)>/traces` with `credentials: "same-origin"`; 200 -> the
   body; any other status -> the status number; a network error -> 0.
4. `test/telemetry-fixtures.ts`: `telemetryOf(patch?: DeepPartial<Telemetry>): Telemetry` (a complete,
   schema-valid zero telemetry: `updatedAt` `2026-11-12T09:01:00.000Z`, sources `["events"]`, model
   `claude-sonnet-5.5`, all counts 0, nullable values null, arrays empty, then the patch merged deeply;
   arrays in the patch replace); `spanOf(patch: Partial<TraceSpan> & { spanId: string }): TraceSpan`
   (kind `chat`, name `chat claude-sonnet-5.5`, startedAt `2026-11-12T09:00:00.000Z`, durationMs 1000,
   status ok, others null, events `[]`); `runOf(patch: Partial<TraceRun> & { traceId: string }): TraceRun`
   (complete true, status ok, startedAt as above, durationMs 10000, agent `copilot`, nanoAiu null,
   turnCount null, spans `[]`, droppedSpans 0). `validateSession` / `validateTracesResponse` from
   `@mc/contracts` must accept a session with `telemetryOf()` and a response with `runOf()`.
