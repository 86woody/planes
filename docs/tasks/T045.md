# T045: Linux discovery and focus (X11, sway, Hyprland, KWin, GNOME, tmux)

Milestone M3 · Wave 2 · Depends on: T003, T013 · Runs on: **Linux** (WSL2 Ubuntu with `xvfb` is enough for the OS tests)

## Goal

Pick a backend per session, find its window, focus and maximize it on X11 and the four
Wayland compositor families, select tmux/kitty/WezTerm panes, and assemble the Linux
adapter. Unsupported compositors return an explicit `none`.

## Steps

1. `backends/select.ts`: `selectBackend(config, displayEnv, host) -> "x11"|"sway"|"hyprland"|"kwin"|"gnome-extension"|"none"`
   (pure, linux.md 1 table in order).
2. Each backend module exports `{ list(): Promise<LinuxWindow[]>; active(): Promise<LinuxWindow | null>; focus(w, opts): Promise<FocusResult> }`
   with `LinuxWindow = {id: string; pid: number; title: string; app: string; stackIndex: number; minimized?: boolean; fullscreen?: number}`
   and pure parsers: `parseWmctrl(stdout)`, `parseSwayTree(json)`, `parseHyprClients(json)`,
   `parseWindowCalls(json)`, and for KWin `kwinScript(params) -> string` (values via
   `JSON.stringify` only). Commands exactly as linux.md 2 and 3. KWin uses
   `dbus-next` (`sessionBus()`, `org.kde.KWin`, `/Scripting`) and the T046 service.
3. `discover.ts`: candidates from the ancestry; `WINDOWID` first on X11; linux.md 2.1
   multi-window rule; tmux (`tmux.ts`, linux.md 4.1) produces the inner selector and the
   outer window; kitty/WezTerm inner selectors from env; `none` backend ->
   `{capability: "none", reason: "wayland_unsupported_compositor"}`; GNOME without the
   D-Bus object -> `gnome_extension_missing`.
4. `focus.ts`: delegate to the backend, then the inner selector, then verify with
   `active()`; result mapping per PA-03 and linux.md 3.
5. `index.ts`: compose; `capabilities()` reports `display`, `focus` per backend
   availability (`which` checks of linux.md 7), issues for missing tools with the fix text.
6. Tests, titles exactly (unit, any OS; fixtures are recorded command outputs):
   - `LU-01 selectBackend follows the linux.md table order including the config override`
   - `LU-02 parseWmctrl reads id, desktop, pid, class and titles with spaces`
   - `LU-03 parseSwayTree finds leaves in nodes and floating_nodes with pid`
   - `LU-04 parseHyprClients reads address, pid, fullscreen`
   - `LU-05 parseWindowCalls reads id, pid, title, focus`
   - `LU-06 kwinScript JSON-escapes a caption containing quotes and backslashes`
   - `LU-07 multi-window process: unique project title wins, else topmost, capability window`
   - `LU-08 tmux: the most recently active client is chosen and commands use -S socket`
   - `LU-09 unsupported Wayland compositor resolves to none/wayland_unsupported_compositor`
   - `LU-10 sway maximize is skipped with detail "tiling: maximize skipped"; Hyprland maximize only when fullscreen is 0`

   OS tests (Linux, `MC_OS_TESTS=1`, inside `xvfb-run` with `openbox`), titles exactly:
   - `LO-01 a spawned xterm resolves by pid to its wmctrl window id`
   - `LO-02 minimized xterm: focus(always) -> focused, both maximized atoms, active window`
   - `LO-03 focus(never): active, not maximized`
   - `LO-04 killed xterm: not_found`
   - `LO-06 tmux inner selector switches the attached client to window 2`
   - `LO-07 /proc ancestry parsing handles a comm with ") ("` (spawn a process via a symlink named `a) (b`)
