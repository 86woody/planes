# T042: Windows toasts and registration

Milestone M3 · Wave 2 · Depends on: T003 · Runs on: **Windows**

## Goal

Show and withdraw WinRT toast notifications under the Mission Control AppUserModelID
with protocol activation, probe whether notifications are possible, and provide the
registry helpers the installer (T051) uses.

## Codes against

`docs/platforms/windows.md` section 5 (normative) and 7, `platform-adapter.md` PA-07,
`internal.md` section 6 (`createNotify`), `api.schema.json` `OsNotification`.

## Files

`packages/platform/src/windows/notify.ts`, `packages/platform/src/windows/registry.ts`,
`packages/platform/src/windows/ps/toast-host.ps1`, `packages/platform/src/windows/toast-host.ts`,
`packages/platform/assets/icon-256.png`,
`packages/platform/test/windows-notify.test.ts`,
`packages/platform/test/os/windows-notify.os.test.ts`, `docs/checkpoints/T042.md`.

## Do not touch

`discover.ts`, `focus.ts`, `win32.ts`, `index.ts`.

## Steps

1. `notify.ts`:
   - `buildToastXml(n, {uri, silent}) -> string` (pure): the XML of windows.md 5.2 with
     every text node XML-escaped (`& < > " '`); `uri = "mission-control://restore/" + encodeURIComponent(n.sessionId)`
     or `mission-control://open` for `sessionId: null`; `silent = !config.notifications.sound || n.urgency === "low"`.
   - `toastTag(tag) -> string`: first 16 hex chars of SHA-256.
   - `toast-host.ts`: `createToastHost(spawnFn)` managing the long-lived
     `ps/toast-host.ps1` process of windows.md 5.2 (Windows PowerShell 5.1 at
     `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`): lazy start,
     newline-delimited JSON requests with incrementing `id`, replies matched by `id`,
     6000 ms timeout for the first request of each process and 2000 ms afterwards, kill
     and restart on timeout or exit, `dispose()` kills it. `spawnFn` is injectable so
     unit tests drive a fake child process.
   - `notify(n, onClick)`: host `show` with `{aumid: "WoodyDeus.MissionControl", tag, group: "mc", xml}`;
     ok -> `{id: tag}`; else null. `onClick` is unused on Windows (clicks come back
     through `mc restore`).
   - `withdraw(h)`: host `remove`.
   - `probe()`: `notify: true` if the AUMID key exists (`reg query`) and PowerShell 5.1
     exists; `notifyClick: true` if the `mission-control` protocol key exists; issues
     `windows_aumid_missing`, `windows_protocol_missing`, `windows_dnd_on`,
     `windows_app_notifications_off` per windows.md 5.4 (fix texts from windows.md 7).
2. `registry.ts` (used by T051): `registerAumid(iconPath)`,
   `registerProtocol({mode: "shim" | "direct", stateDir, nodePath, mcJsPath})` (windows.md 5.1:
   shim mode also returns the `restore.vbs` text for the installer to write, built by a
   pure `restoreVbs(nodePath, mcJsPath)`),
   `unregisterAll()`, each building `reg.exe add|delete` argument arrays (pure builder
   `regCommands(...) -> string[][]` + a runner).
3. `ps/toast-host.ps1`: first set `[Console]::InputEncoding` and `[Console]::OutputEncoding`
   to UTF-8 without BOM (windows.md 5.2; titles contain `·`), then load the WinRT types once, then loop `while (($line = [Console]::In.ReadLine()) -ne $null)`;
   parse with `ConvertFrom-Json`; `show` runs the windows.md 5.2 snippet; `remove` runs
   `[Windows.UI.Notifications.ToastNotificationManager]::History.Remove($tag, $group, $aumid)`;
   `history` returns the tags of `History.GetHistory($aumid)` (for WO-06); each reply
   `ConvertTo-Json -Compress` written with `[Console]::Out.WriteLine` and flushed;
   every operation inside `try/catch` replying `{"id", "ok": false, "error"}`.
4. `assets/icon-256.png`: a 256x256 PNG, black background with the `▸` chevron in
   `#3FC1FF` (generate it with a tiny script using only Node built-ins: write an
   uncompressed PNG via `zlib.deflateSync`; commit the PNG, not the script).
5. Tests, titles exactly (unit, any OS):
   - `WU-13 buildToastXml escapes title and body and sets protocol activation with the encoded id`
   - `WU-14 summary notification uses mission-control://open`
   - `WU-15 toastTag is 16 hex chars and stable`
   - `WU-16 regCommands produce the exact keys and values of windows.md 5.1`
   - `WU-17 restoreVbs embeds node and mc.js paths and its guard rejects arguments with a quote or another scheme`
   - `WU-18 toast host: replies are matched by id, first request gets 6000 ms, a later timeout kills and restarts the host, and the request line for a title with · is valid UTF-8` (fake child process, fake timers)

   OS test (Windows, `MC_OS_TESTS=1`; registers the AUMID under the test's own id
   `WoodyDeus.MissionControl.Test` and removes it after), title exactly:
   - `WO-06 a shown toast appears in History.GetHistory within 2 s and withdraw removes it`
