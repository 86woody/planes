# T103: W- checklist findings: conhost inside Windows Terminal, doctor notification check (D-50)

Milestone M5 · Wave 8i · Depends on: T012, T050 · Runs on: any OS

## Goal

Two defects the W- checklist (2026-11-16) recorded and did not fix:

1. `conhost pwsh` started from a shell inside Windows Terminal was labelled Windows
   Terminal (MC-30, MC-31): it inherits `WT_SESSION` and has WT as an ancestor, and
   ingest.md host rule 4 matched first. Its window is a classic console.
2. `mc doctor` warned "App notifications enabled" while notifications were on: Windows
   leaves the `Enabled` value out when an app's notifications are on, and the check
   required `Enabled = 1`.
