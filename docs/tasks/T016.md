# T016: Persistence (snapshot, event log, spool)

Milestone M1 · Wave 1 · Depends on: M0 · Runs on: any OS

## Goal

Save and load `sessions.json` atomically, append `events.jsonl` with rotation, and read
and delete hook spool files.

## Codes against

`docs/contracts/config.md` section 2 (file formats), `internal.md` (`Persistence`,
`PersistedState`, `createPersistence`), D-11, D-14.

## Files

`packages/daemon/src/persistence.ts`, `packages/daemon/test/persistence.test.ts`,
`docs/checkpoints/T016.md`.

## Do not touch

Everything else. Build `Paths` in tests by hand (do not import `paths.ts`: T014 writes
it in parallel).

## Steps

1. `load()`: read `sessionsFile`; missing -> `{version: 1, callsignCounter: 0, records: []}`;
   invalid JSON or `version !== 1` -> rename to `sessions.json.corrupt-<ms>` and return empty.
   Each record's `session` is validated with `validateSession`; invalid records are
   dropped (count them in a log line).
2. `scheduleSave(get)`: debounce 500 ms (`setTimeout`, reset on each call); write
   `sessions.json.tmp` with `fs.promises.open` + `write` + `sync` + `close`, then
   `rename` over the target. `flush()` runs a pending save now and awaits it.
3. `appendEvent(env, receivedAt)`: append `JSON.stringify({receivedAt, envelope}) + "\n"`
   with `fs.appendFileSync` (ordering matters more than speed); before appending, if the
   file is >= 10 MiB, rename it to `events.jsonl.1` (replacing an old `.1`).
4. `readSpool()`: list `spoolDir` (missing -> []), only `*.json`, sorted by name, parse
   each (unparseable -> returned with `envelope: null` so the caller deletes it).
   `deleteSpool(file)` ignores ENOENT.
5. Tests, titles exactly:
   - `PS-01 save then load round-trips records and callsignCounter` (fake timers to fire the debounce, then `flush`)
   - `PS-02 corrupt sessions.json is renamed and load returns empty`
   - `PS-03 events.jsonl rotates at 10 MiB and spool files are read in name order`
