# T051: Installers: claude-code, codex, shell, uri-handler, autostart, vscode

Milestone M4 · Wave 5 · Depends on: T027 · Runs on: any OS

## Goal

`mc install <target>` and `mc uninstall <target>`: write exactly what each integration
needs, record it in the install manifest, and remove exactly that.

## Codes against

`docs/contracts/claude-hooks.md` (normative), `ingest.md` 6.1 (codex), D-18 and
`ingest.md` 6.2 (shell), `platforms/windows.md` 5.1 and 6, `macos.md` 5, `linux.md` 6,
`config.md` (`install-manifest.json`), PRD AC-15.

## Files

`packages/cli/src/commands/{install,uninstall}.ts`, `packages/cli/src/installers/{claude,codex,shell,uri,autostart,vscode,manifest,json-edit}.ts`,
`packages/cli/test/{install-claude,install-other}.test.ts`, `packages/cli/test/fixtures/**`,
`docs/checkpoints/T051.md`.

## Do not touch

T050's commands, `assets/shell/**` (T053 writes the snippets; you copy/reference them by path).
Use `packages/platform/src/windows/registry.ts` (T042) for Windows registry writes.

## Steps

1. `mc install claude-code [--dry-run]`: claude-hooks.md sections 1-3 exactly. Also runs
   `uri-handler` install on Windows and Linux (once; skipped if in the manifest).
2. `mc install codex`: ingest.md 6.1 (edit TOML by line: if a line matching
   `^\s*notify\s*=` exists, exit 1 with the manual-merge message; else append
   `notify = ["<node>", "<hook js>", "codex"]` at the top level, before the first `[table]`).
3. `mc install shell --pwsh|--bash|--zsh`: append one marked block to the profile file
   (`$PROFILE.CurrentUserAllHosts` path from `pwsh -NoProfile -Command '$PROFILE.CurrentUserAllHosts'`,
   `~/.bashrc`, `~/.zshrc`):
   `# >>> mission-control >>>` / `. "<repo>/packages/cli/assets/shell/mc.<ext>"` / `# <<< mission-control <<<`.
   Also writes `<stateDir>/shell.env` with two lines `MC_NODE=<process.execPath>` and
   `MC_HOOK_JS=<repo>/packages/hook/dist/mc-hook.js` (read by the T053 snippets), and sets
   `adapters.shell.enabled: true` in config.json (create if absent, preserve keys).
4. `mc install uri-handler [--direct]`: Windows `registerAumid` + `registerProtocol` (default
   `mode: "shim"`: also write `<stateDir>\restore.vbs` with the text `registerProtocol`
   returns; `--direct` writes the plain node command, windows.md 5.1); Linux the
   `.desktop` file + `xdg-mime`; macOS prints `not needed on macOS` and exits 0.
5. `mc install autostart`: windows.md 6, macos.md 5, linux.md 6.
6. `mc install vscode`: `pnpm --filter @mc/vscode-bridge build`, then
   `pnpm --filter @mc/vscode-bridge exec vsce package --no-dependencies -o <stateDir>/mission-control-bridge.vsix`
   (`@vscode/vsce` is a dev dependency declared by T001), then
   `code --install-extension <vsix>` (also `code-insiders`, `cursor` if on PATH).
7. Every installer records `{target: {...exact things written...}}` in
   `install-manifest.json`; `uninstall <target>` reverses from the manifest only.
8. `json-edit.ts`: parse, mutate, `JSON.stringify(x, null, 2) + "\n"`, write via temp +
   rename; backup `<file>.mc-backup-<yyyyMMddHHmmss>` before the first write.
9. Tests use temp `HOME`/`USERPROFILE`, `CLAUDE_CONFIG_DIR`, `MC_HOME`; Windows registry
   and `code`/`xdg-mime`/`launchctl`/`systemctl` calls go through an injected `runner`
   that records argument arrays (never executed in tests). Titles exactly:
   - `IC-01 install adds one group per event of claude-hooks.md with the exec-form hook object (command = node path, args = [hook js, claude-code])`
   - `IC-02 existing user hooks are kept in order and untouched`
   - `IC-03 install twice adds nothing the second time`
   - `IC-04 a backup file is written before the first change`
   - `IC-05 invalid settings JSON: exit 1, file unchanged`
   - `IC-06 uninstall removes exactly the recorded entries and empty arrays, leaving other keys`
   - `IC-07 --dry-run prints a diff and writes nothing`
   - `IC-08 SessionEnd is the only synchronous entry, with timeout 2`
   - `IX-01 codex install appends notify before the first table`
   - `IX-02 codex install with an existing notify exits 1 and changes nothing`
   - `IX-03 shell install appends the marked block once and enables the shell adapter`
   - `IX-04 shell uninstall removes the marked block only`
   - `IX-05 uri-handler on windows issues the registry commands of windows.md 5.1 (wscript shim) and writes restore.vbs; --direct writes the node command`
   - `IX-06 uri-handler on linux writes the desktop file and calls xdg-mime`
   - `IX-07 autostart writes the per-OS artefact and records it in the manifest`
   - `IX-08 vscode install runs build, vsce package and code --install-extension in order`
