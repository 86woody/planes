# T096 checkpoint: installed mc runs through the npm shim

Host: dev-pc. Branch: task/T096-shebang.

## What works

- `scripts/package.mjs`: after the package.json is written, `ensureShebangs` makes every
  file named in the generated `bin` start with `#!/usr/bin/env node` as its first line.
  It strips an existing leading node shebang before prepending, so `mc-hook.js` never gets
  two.
- `packaging-test/package.test.mjs`: PK-10 `every bin file in the package starts with the
  node shebang` checks the first line and that the shebang appears exactly once per bin file.
- `packaging-test/install.test.mjs`:
  - `shimPath(prefix, name = "mc")` now takes the bin name.
  - `mc()` runs `shimPath(prefix)` through a `runShim` helper. On Windows that is
    `cmd.exe /d /s /c "<shim> <args>"` with `windowsVerbatimArguments`; on Linux it runs
    `<prefix>/bin/<name>` directly. The env and timeout are kept.
  - SK-07 `the installed mc-hook shim runs the hook and exits 0` runs the `mc-hook` shim with
    `claude-code` and the SessionStart fixture on stdin, and expects exit 0 within 1500 ms.
  - The unused `pkgDir` helper was removed, because lint flagged it.

## Results

- Acceptance command: exit 0. PK-10 is green, and SK-01..SK-07 run through the shim.
  `TASK T096 PASS 2/2`, `TASK T087 PASS 8/8`, `TASK T089 PASS 6/6`.
- `pnpm -w run typecheck`: exit 0.
- `pnpm -w run lint`: exit 0 (after the `pkgDir` removal).
- Direct shim run in a temp `--prefix` (`npm i -g --prefix`), with MC_HOME and
  CLAUDE_CONFIG_DIR in temp dirs: `mc.cmd --version` printed `1.0.0` and exited 0.
- The built `dist/mc-hook.js` starts with `#!/usr/bin/env node`.
- No daemon was started by this task. SK-04 starts and stops its own daemon.

## What does not work / open

- Nothing open in the acceptance path. The Linux branch of `runShim` and the Linux shim
  path are written but not run (this is a Windows machine).

## Surprises

- Running `cmd.exe /d /s /c "..."` from the Bash tool mangled the quoting and dropped into
  an interactive banner, so the direct shim run was done from PowerShell instead.
- Node needs `windowsVerbatimArguments: true` for the cmd.exe line, or the quotes inside the
  command line are escaped with backslashes that cmd does not understand.
- `scripts/package.mjs` already logs a DEP0190 deprecation warning from its `sh()` helper
  (`shell: true` with args). It predates this task and was left alone.
