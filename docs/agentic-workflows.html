Twenty Agentic Workflows

This reference shows twenty patterns that connect language models, tools and people into agentic systems. Each card has a diagram, a description, a condition for use and the primary risk. Start with the simplest pattern that does the task. Add steps only when a test shows that you need them.

The text follows approximately 80% of the ASD-STE100 Simplified Technical English rules. Sentences are short and active, and each sentence has one idea. Technical names, for example context window and map-reduce, are not in the STE dictionary. STE permits them as technical names. The bars under each card show the length of each sentence against the 25-word limit for descriptive text.
