# T040: Windows discovery, win32 bindings, adapter assembly

Milestone M3 · Wave 2 · Depends on: T003, T013 · Runs on: **Windows** (dev-pc)

## Goal

Find the window of a Windows session (conhost, Windows Terminal, unknown hosts), report
the foreground window, list windows by app, and assemble the Windows `PlatformAdapter`
from discover, focus (T041) and notify (T042).

## Codes against

`docs/platforms/windows.md` sections 1, 2 (normative), `platform-adapter.md` (all),
`internal.md` section 6 (`Discover`, `createDiscover`, `create`, `PlatformEnv`),
`ingest.md` section 3 (`console` fields).

## Steps

1. `win32.ts`: koffi bindings (lazy: create on first use) for the functions listed in
   windows.md 2, plus `EnumWindows` with a koffi callback prototype
   `BOOL EnumWindowsProc(HWND, LPARAM)`. Helpers: `hwndToHex(h): string` (`0x` + 16
   uppercase hex) and `hexToHwnd(s)`; `windowInfo(h) -> {pid, exe, className, title, visible, owner}`.
2. `discover.ts`: `createDiscover({exec, env})` implementing windows.md 2 steps 1-5 and
   2.1-2.2. Structure the decision logic as a pure function
   `chooseWindow(input: {origin, host, windows: WindowInfo[], byHwnd: (hex) => WindowInfo | undefined}) -> ResolvedTarget`
   so it is unit-testable with fixtures on any OS; the impure part only gathers
   `windows` (one EnumWindows pass) and `byHwnd`.
   Inner selector: for `windows-terminal`, `inner = {wtTabTitle: <window title>}`
   (T041 re-runs the tab heuristic at focus time); capability `full` for conhost;
   for WT `full` (T041 downgrades to `focused_window_only` at focus time if the tab is
   not unique); `window` for unknown hosts; elevated owning process -> `none`,
   `platform_error`, detail `target window is elevated`.
3. `index.ts` `create(env)`: compose `createDiscover`, `createFocus` (from `./focus.js`),
   `createNotify` (from `./notify.js`), `processAlive` from `../process/index.js`;
   `capabilities()` = `{os: "windows", display: "win32", focus: "full", ...notify.probe()}`;
   `dispose()` calls `notify.dispose()`.
4. Fixtures (`fixtures/windows/*.json`): recorded `WindowInfo` lists and origins for:
   conhost, WT with ownerHwnd, WT without ownerHwnd and 2 WT windows, unknown host with
   a titled ancestor window, elevated WT, WSL origin with one WT window.
5. Tests, titles exactly (unit, any OS):
   - `WU-01 conhost: ConsoleWindowClass consoleHwnd is chosen, capability full`
   - `WU-02 ownerHwnd owned by WindowsTerminal.exe is chosen with wtTabTitle`
   - `WU-03 PseudoConsoleWindow consoleHwnd resolves through its root owner`
   - `WU-04 two WT windows and no ownerHwnd -> none/no_window_found "ambiguous: 2 windows"`
   - `WU-05 unknown host takes the first ancestor with a visible unowned titled window, capability window`
   - `WU-06 elevated owner -> none/platform_error and WSL origin with one WT window -> window`

   OS tests (`MC_OS_TESTS=1`, Windows only), titles exactly:
   - `WO-01 a spawned conhost cmd window resolves to ConsoleWindowClass`
   - `WO-05 processAlive true with start time, false with another, false after exit`
   - `WO-08 ancestry of a child node process lists this process with its name`
