# T083: Launchers and installer paths

Milestone M5 · Wave 8c · Depends on: T081 · Runs on: any OS

## Goal

Every path an installer writes for a hook, `mc` or the restore handler points at a stable
launcher in `<stateDir>/bin/` instead of at the clone, and every asset the installers read
comes from `layout()`. The launcher is a two-line CommonJS file that `import()`s the real
entry file, so a moved install is healed by rewriting one launcher, not by touching
`settings.json`.

## Steps

1. Create `packages/cli/src/installers/launcher.ts`, exactly this API (PACKAGING.md 4):

   ```ts
   import { existsSync, readFileSync } from "node:fs";
   import path from "node:path";
   import { pathToFileURL } from "node:url";
   import type { Layout } from "@mc/platform/layout";
   import { writeAtomic } from "./json-edit.js";

   export interface LauncherPaths { readonly dir: string; readonly hookJs: string; readonly mcJs: string }
   export function launcherPaths(stateDir: string): LauncherPaths {
     const dir = path.join(stateDir, "bin");
     return { dir, hookJs: path.join(dir, "mc-hook.js"), mcJs: path.join(dir, "mc.js") };
   }
   export function launcherText(kind: "hook" | "mc", target: string, version: string): string {
     const exit = kind === "hook" ? 0 : 1;
     return (
       `// mission-control launcher. target: ${target}. version: ${version}\n` +
       `import(${JSON.stringify(pathToFileURL(target).href)}).catch((e) => { process.stderr.write(String(e && e.stack || e) + "\\n"); process.exit(${exit}); });\n`
     );
   }
   ```

   `readLauncherTarget(file)`: returns `null` when the file is missing or its first line
   (trailing `\r` stripped) does not match `/^\/\/ mission-control launcher\. target: (.*)\. version: (.*)$/`;
   otherwise group 1.
   `writeLaunchers(stateDir, lay)`: `bin = launcherPaths(stateDir)`;
   `changed = readLauncherTarget(bin.hookJs) !== lay.hookJs || readLauncherTarget(bin.mcJs) !== lay.mcJs`
   (computed first); then `writeAtomic` (it creates the directory) for `bin.dir/package.json`
   with the text `{"type":"commonjs"}\n`, for `bin.hookJs` with `launcherText("hook", lay.hookJs, lay.version)`
   and for `bin.mcJs` with `launcherText("mc", lay.mcJs, lay.version)`, but only when the
   file's current text differs from the new text (an unchanged file is not rewritten, and a
   version-only difference rewrites the file without setting `changed`). Return `{ changed }`.
