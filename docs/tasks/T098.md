# T098: `mc init --agents` splits on whitespace too (npm's PowerShell shim)

Milestone M5 · Wave 8h · Depends on: T097 · Runs on: any OS

## Goal

T097 assumed PowerShell passes an unquoted `claude-code,copilot` as two words. Through npm's
`mc.ps1` shim (`& node ... $args`), PowerShell 5.1 and 7 both join the array into one
argument with a space: node receives `["init","--agents","claude-code copilot"]`. This was
measured on dev-pc with a probe shim. The fresh-machine run (FM-06) still exits 2 with
the usage line. After this task, each `--agents` word is split on commas and on whitespace.

## Steps

1. In `parseInitArgs`, split each collected word on `/[\s,]+/` instead of `","`. Everything
   else stays as T097 left it: trim, lower-case, drop empty pieces, de-duplicate, keep menu
   order, and return USAGE for unknown agents, an empty list or a stray `--` argument.
2. Add the test `IN-14 --agents accepts one word holding a space-separated list (npm's PowerShell shim)`.
   It expects:
   - `parseInitArgs(["--agents", "claude-code copilot"])` and
     `parseInitArgs(["--agents", " claude-code ,  copilot "])` select the same two agents as
     `["--agents", "claude-code,copilot"]`;
   - `parseInitArgs(["--agents", "claude-code nope"])` returns the usage string.
