# T102: an elevated target window gets its own restore reason, `target_elevated` (D-49)

Milestone M5 · Wave 8i · Depends on: T040, T100 · Runs on: any OS

## Goal

W-10 (2026-11-16) failed: for a Claude session in an elevated Windows Terminal the card shows
capability "None" and nothing about elevation. Discovery returned `none/platform_error`
without the detail the Windows spec names, and the board explains `platform_error` only
through a `FocusResult` detail. D-49 adds `RestoreReason` `target_elevated` with a fix-it text.
