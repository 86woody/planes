# T052: VS Code bridge extension

Milestone M4 · Wave 5 · Depends on: T027 · Runs on: any OS

## Goal

The extension inside each VS Code window: connect to the daemon, report workspace and
terminals with shell PIDs, follow focus changes, and show the right terminal or the
Claude panel on request.

## Codes against

`docs/contracts/vscode-bridge.md` (all, normative), `config.md` sections 1-2 (paths for
port and token), D-07, D-08.

## Files

`packages/vscode-bridge/src/{extension,client,paths,terminals}.ts`,
`packages/vscode-bridge/test/{extension.test.ts,vscode-mock.ts}`,
`packages/vscode-bridge/README.md`, `docs/checkpoints/T052.md`.

## Do not touch

Everything outside `packages/vscode-bridge` (its `package.json` manifest is T001's;
if you need a contribution point, stop with a CR).

## Steps

1. `paths.ts`: config.md section 1 (third copy; tested against
   `packages/daemon/test/fixtures/paths.json`).
2. `client.ts`: `ws` client with `Authorization: Bearer`, backoff 1, 2, 5, 10 s;
   sends `hello` on open; handles `welcome`, `focusTerminal`, `focusAgentPanel`; replies
   `result` within 2 s.
3. `terminals.ts`: track `vscode.window.terminals`, assign `t<n>` ids in a `WeakMap`,
   `await terminal.processId` (null for remote windows), send the full list debounced
   200 ms on open/close/change-active/state changes.
4. `extension.ts`: `activate(ctx)`: `windowId = crypto.randomUUID()`; start the client;
   subscribe `onDidChangeWindowState`; `deactivate` closes the socket.
   `focusAgentPanel`: `CLAUDE_PANEL_COMMANDS` per vscode-bridge.md 4, first one present
   in `getCommands(true)`.
5. Ship `CLAUDE_PANEL_COMMANDS` exactly as vscode-bridge.md 4 lists it. Finding the real
   command id needs a VS Code with the Claude Code extension installed, which is the
   orchestrator's post-merge manual step (ORCHESTRATION.md 7), not yours.
6. `README.md`: what it does, `pnpm mc install vscode`, no settings.
7. Tests with `vscode-mock.ts` (a minimal fake of `window.terminals`, events,
   `commands.getCommands/executeCommand`, `env`, `workspace`) and a real `ws` server on
   port 0 standing in for the daemon. Titles exactly:
   - `VB-01 hello carries windowId, extHostPid, workspace name and folders, focused`
   - `VB-02 terminals list includes shellPid and active, debounced to one message`
   - `VB-03 window focus change sends windowState`
   - `VB-04 focusTerminal shows the terminal and replies ok`
   - `VB-05 focusTerminal for a closed terminal replies terminal_gone`
   - `VB-06 focusAgentPanel runs the first available Claude command, or replies no_panel_command`
   - `VB-07 reconnect backoff is 1, 2, 5, 10, 10 s` (fake timers)
   - `VB-08 paths match fixtures/paths.json`
