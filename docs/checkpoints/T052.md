# T052 checkpoint: VS Code bridge extension

## What works

- `paths.ts`: `resolvePaths(env, platform, home)` implements config.md section 1 and 2. It
  uses `path.win32` or `path.posix` by the platform argument, so fixture cases for every
  OS resolve the same on any host. VB-08 passes against `packages/daemon/test/fixtures/paths.json`.
- `client.ts`: `BridgeClient` connects to `ws://127.0.0.1:<port>/bridge/v1` with
  `Authorization: Bearer`, sends `hello` on open, answers `focusTerminal` and
  `focusAgentPanel` with `result`, and reconnects with backoff 1, 2, 5, 10, 10 s (VB-07
  uses fake timers and an injected socket factory). The backoff resets on `welcome`.
  Port comes from `daemon.json` and the token from `stateDir/token`, both re-read on every
  attempt.
- `terminals.ts`: `TerminalTracker` gives stable `t<n>` ids through a `WeakMap`, reads
  `processId` (null for remote windows and for failed promises), and emits full snapshots
  debounced 200 ms on open, close, active change and state change.
- `extension.ts`: `activate` makes a `randomUUID()` windowId, starts the client, forwards
  `onDidChangeWindowState`, and `deactivate` closes the socket. `focusTerminal` returns
  `terminal_gone` for an unknown id. `focusAgentPanel` returns `no_panel_command` when no
  candidate is present.
- Tests VB-01..VB-08 run with `vscode-mock.ts` (aliased to `vscode` by
  `vitest.workspace.ts`) and a real `ws` server on port 0. No test touches the real config
  or state dirs (`MC_HOME` points at a temp dir), and no test sleeps longer than 2 s.
- Acceptance command: `TASK T052 PASS 8/8`, exit 0. `pnpm -w run typecheck` and
  `pnpm -w run lint` exit 0.

## What does not

- Nothing in the task scope is left undone. The extension has not been run in a real VS
  Code window (out of scope: the task forbids installing it into the real VS Code).
- `focusTerminal` with `maximizePanel: true` always runs
  `workbench.action.toggleMaximizedPanel`. The contract says the panel state is unknowable
  and the daemon always sends `false` in v1, so this branch is untested by design.
