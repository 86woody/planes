# T120: the list view gets five sortable telemetry columns and an Open link (D-58)

Milestone M5 · Wave 10b · Depends on: T119 · Runs on: any OS

## Goal

Compare every session side by side by cost, token rate, context, time waiting on you and
failed tools, and open any session's page from its row.

## Steps

1. `ListView.tsx` keeps its props, its existing columns, testids and default order unchanged (CARD-
   tests in `card.test.tsx` and `e2e/` must still pass). Import `../list-tele.css` at the top.
2. Sort state inside `ListView`: `useState<{ key: SortKey; dir: "desc" | "asc" } | null>(null)`.
   null = the existing "who needs you" order.
3. After the `Waited / up` column add five `th` cells, in order Credits (`credits`), Tok/min (`rate`),
   Context (`ctx`), Waited on you (`waited`), Failed tools (`failed`). Each `th` has `aria-sort`
   (`descending`, `ascending`, or `none`) and contains one `<button type="button" className="sorth"
   data-testid="sort-<key>">` with the label. A click: null or another key -> that key desc; same key
   desc -> asc; same key asc -> null.
4. Ordering when a sort is set: the live sessions by `sortValue` in the chosen direction, sessions
   whose value is null last (in both directions), ties by the existing order. The "Ended and lost"
   group keeps its own order and is not sorted. The header line becomes
   `N · sorted by <label> ↓` (desc) or `↑` (asc) instead of `sorted by who needs you`; keep `· L to close`.
5. Cells, `data-testid="t-<key>"`, class `num mono` (Waited on you and Failed tools also `num mono`):
   - no telemetry: `availabilityText(availability(s))` in `--ink3` (class `na`) in every one of the five.
   - credits: `credits(t).text`, the unit in a `<small>` after it when not empty.
   - rate: `rateText(t.tokenRate)`.
   - ctx: `contextText(t)`; when `contextOver(t)` add class `over` and a visually hidden ` Over 85%`
     (`<span className="sr-only">`), and the cell shows `data-over="true"`.
   - waited: `wait(waitedMs(t))`.
   - failed: `failedTools(t)`; above 0 add class `over` and `data-over="true"`.
6. Column visibility: Context, Waited on you and Failed tools carry class `hw` (hidden under 1180px);
   all five carry class `ht` (hidden under 760px). Write those two media rules in `list-tele.css`,
   plus `.listv .over { color: var(--look); }`, `.listv .na { color: var(--ink3); }`, and the
   `.sorth` button: no border, no background, inherit font and colour, `cursor: pointer`, a 2px
   `--ink2` focus outline.
7. In the actions cell, before Restore, every live row (not ended or lost) gets
   `<a className="btn" data-testid="open-session" href={routeHref({ page: "session", id: s.id })}
   onClick={(e) => e.stopPropagation()}>Open</a>`.
8. The `colSpan` of the "Ended and lost" group row becomes 12.

## Tests (`packages/ui/test/list-tele.test.tsx`; mount like `card.test.tsx`; NOW fixed)

- `LS-01` three live sessions with telemetry and one shell session without: the five cells show the
  formatted values (`12.35` + `AI Credits`, `1,234`, `≈42%`, `01:12`, `2`), the shell row shows `n/a`.
- `LS-02` clicking `sort-credits` orders rows by credits descending, again ascending, a third time back
  to the default order; the session without telemetry is last in both directions; `aria-sort` follows;
  the header line says `sorted by Credits ↓` then `↑`.
- `LS-03` context 86 sets `data-over="true"` on `t-ctx`, 85 does not; failed tools 1 sets it on `t-failed`.
- `LS-04` a live row has `open-session` with href `#/s/<encoded id>`; an ended row has none; clicking it
  does not call `deck.select`.
