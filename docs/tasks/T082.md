# T082: Rewire platform and daemon consumers to layout()

Milestone M5 · Wave 8c · Depends on: T081 · Runs on: any OS

## Goal

Every platform adapter and the daemon get their shipped-file paths and the version from
`layout()` instead of computing "N levels up" from the clone. After this task nothing
under `packages/platform/src/{windows,linux,macos}` reads `env.repoRoot`, and the daemon
reports the root `package.json` version (D-44.2).

## Codes against

`docs/PACKAGING.md` sections 3 and 8, `docs/DECISIONS.md` D-40 and D-44.

## Files

`packages/platform/src/windows/{notify,focus}.ts`, `packages/platform/src/linux/notify.ts`,
`packages/platform/src/macos/{discover,notify}.ts`, `packages/daemon/src/main.ts`,
`packages/daemon/test/layout-wiring.test.ts`, `docs/checkpoints/T082.md`.

## Do not touch

Every other file. In particular `packages/platform/src/types.ts` (frozen; `PlatformEnv.repoRoot`
stays in the interface, it is just no longer read by the adapters), `packages/platform/src/layout.ts`
(T081), `packages/cli/src/**` (T083-T086 rewire the installers and `lib/paths.ts`), and
`vitest.workspace.ts`.

Precondition: T080 made `vitest.workspace.ts` resolve `@mc/platform/layout` to `packages/platform/src/layout.ts` (check with
`grep -n "platform/layout" vitest.workspace.ts`). If there is no such line, write
`CR: vitest.workspace.ts alias for @mc/platform/layout missing (T080)` in the checkpoint and stop.

## Steps

How `repoRoot` flows today: `packages/daemon/src/main.ts:190` computes
`repoRoot` (three levels up from `main.js`) and puts it in `platformEnv`
(`main.ts:191-197`, type `PlatformEnv` at `packages/platform/src/types.ts:80`); `createPlatform(platformEnv)`
passes it to each adapter as `deps.env.repoRoot`. Only the places in steps 1-5 read it. All
of them now call `layout()` and ignore `repoRoot`.

In the four platform files add `import { layout } from "../layout.js";` (same directory depth
for all of them). Remove any import that becomes unused (`fileURLToPath`, `dirname`, `join`...);
`pnpm -w run lint` fails on unused imports.

1. `packages/platform/src/windows/notify.ts:75`: replace the `path.join(deps.env.repoRoot, "packages", "platform", "src", "windows", "ps", "toast-host.ps1")`
   with `path.join(layout().psDir, "toast-host.ps1")`.
2. `packages/platform/src/windows/focus.ts:341` (`selectWtTab`): replace
   `const dir = path.join(deps.env.repoRoot, "packages", "platform", "src", "windows", "ps");`
   with `const dir = layout().psDir;`. The `wt-tabs.ps1` and `wt-select-tab.ps1` joins stay.
3. `packages/platform/src/linux/notify.ts:160`: replace the `icon` computation with
   `const icon = layout().iconPath;`.
4. `packages/platform/src/macos/discover.ts:26-28`: `scriptPath(name)` becomes
   `return path.join(layout().macosScriptsDir, name);` (import `path from "node:path"`; drop the
   `fileURLToPath` import if unused).
5. `packages/platform/src/macos/notify.ts`:
   - remove the module constants `SCRIPT_DIR` (line 12) and `OSASCRIPT_FILE` (line 14);
     in `osascriptArgs` (line 68) return `[join(layout().macosScriptsDir, "notify-osascript.applescript"), n.title, n.body]`
     (these constants were evaluated at import time; `layout()` is called lazily instead);
   - line 93: `const mcJs = layout().mcJs;` (replaces `join(deps.env.repoRoot, "packages", "cli", "dist", "mc.js")`);
   - remove the `dirname` and `fileURLToPath` imports if now unused.
6. `packages/daemon/src/main.ts`:
   - add `import { layout } from "@mc/platform/layout";`
   - delete the module constant `DAEMON_VERSION` (lines 58-60, the `readFileSync(new URL("../package.json", ...))` read);
   - at the top of `startDaemon`, after `const { env, foreground } = opts;`, add `const lay = layout();`;
   - replace the three `DAEMON_VERSION` uses (`version: DAEMON_VERSION` in `deps`, in the `daemon.json` write, and in the `log.info` call) with `lay.version`;
   - delete the `repoRoot` computation and its comment (lines 189-190); in `platformEnv` write `repoRoot: lay.root,`
     (the interface still requires the key; nothing reads it any more);
   - replace `const uiCandidate = path.join(repoRoot, "packages", "ui", "dist"); const uiDir = existsSync(uiCandidate) ? uiCandidate : null;`
     with `const uiDir = existsSync(lay.uiDir) ? lay.uiDir : null;`;
   - drop imports left unused (`fileURLToPath`, `readFileSync` if nothing else uses it; check with lint).
7. Tests in `packages/daemon/test/layout-wiring.test.ts`. This file falls under the Vitest project
   `daemon` (`vitest.workspace.ts`: `packages/daemon/test/**/*.test.ts`, which excludes only
   `integration/**` and `budget.test.ts`), so no config change. Import platform modules by relative path
   (`../../platform/src/...`) and `layout` from `../../platform/src/layout.js`. Use a fake env whose
   `repoRoot` is `"/nonexistent-repo"` so any leftover use of it fails the test. Titles exactly:
   - `RW-01 windows createNotify spawns the toast host from layout().psDir`
   - `RW-02 windows focus takes the ps1 directory from layout().psDir`
   - `RW-03 linux notify sends layout().iconPath as the app icon`
   - `RW-04 macos scriptPath resolves under layout().macosScriptsDir`
   - `RW-05 macos osascriptArgs starts with the notify-osascript.applescript file under layout().macosScriptsDir`
   - `RW-06 macos notify takes mc.js from layout().mcJs`
   - `RW-07 no source file under platform/src/windows, linux or macos reads repoRoot`
   - `RW-08 daemon main.ts has no clone-relative uiDir or package.json version code and uses layout()`
   - `RW-09 a started daemon reports the root package.json version on /healthz`

   How to assert:
   - RW-01: before the imports, `const { spawnToastHost } = vi.hoisted(() => ({ spawnToastHost: vi.fn(() => () => { throw new Error("not spawned"); }) }));`
     and `vi.mock("../../platform/src/windows/toast-host.js", () => ({ spawnToastHost, createToastHost: () => ({ request: async () => null, dispose: () => undefined }), powershellPath: () => "powershell.exe" }));`.
     Then `createNotify({ exec: stubExec, env })` and `expect(spawnToastHost).toHaveBeenCalledWith(path.join(layout().psDir, "toast-host.ps1"))`.
     `stubExec` is `async () => ({ code: 0, stdout: "", stderr: "", timedOut: false })`.
   - RW-02, RW-06: read the file with `readFileSync`; expect it to contain `layout().psDir` (RW-02) or
     `layout().mcJs` (RW-06), and not to contain `repoRoot`.
   - RW-03: `createNotifyWithConnector({ exec: stubExec, env }, async () => conn)` where `conn` is
     `{ capabilities: async () => [], notify: async (a) => { seen.push(a); return 1; }, close: async () => undefined, onActionInvoked: () => undefined, onClosed: () => undefined, disconnect: () => undefined }`;
     `await adapter.notify({ sessionId: "s1", title: "t", body: "b", urgency: "normal", tag: "tag-1" }, () => undefined)`;
     expect `seen[0][2]` to be `layout().iconPath`.
   - RW-04: `scriptPath("ax-list.js")` from `../../platform/src/macos/discover.js` equals `path.join(layout().macosScriptsDir, "ax-list.js")`.
   - RW-05: `osascriptArgs(notification)[0]` from `../../platform/src/macos/notify.js` equals
     `path.join(layout().macosScriptsDir, "notify-osascript.applescript")`.
   - RW-07: walk those three directories recursively (`readdirSync(dir, { recursive: true })`, `.ts` files) and expect no file's text to match `/\brepoRoot\b/`.
   - RW-08: read `packages/daemon/src/main.ts`; expect it to contain `@mc/platform/layout`, `lay.uiDir`,
     `lay.version`, and not to match `/"\.\.\/package\.json"/` nor `/DAEMON_VERSION/`.
   - RW-09: temp `MC_HOME` (`fs.mkdtempSync(path.join(os.tmpdir(), "mc-rw-"))`),
     `const d = await startDaemon({ env: { MC_HOME: home, MC_PLATFORM: "fake", MC_PORT: "0" }, foreground: false })`
     (import `startDaemon` from `../src/main.js`), `fetch("http://127.0.0.1:" + d.port + "/healthz")`,
     expect `json.version` to be the `version` string in the repo root `package.json`
     (read it in the test); `await d.stop()` and remove the temp dir in `finally`.
8. Run the acceptance command, plus `pnpm -w run typecheck` and `pnpm -w run lint`. Also run
   `pnpm vitest run packages/platform packages/daemon` and confirm nothing that passed before fails
   (the existing `linux-notify` and `macos-notify` tests pass a fake `repoRoot`, which is now ignored).
