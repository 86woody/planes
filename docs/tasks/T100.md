## Requirements

1. **Data:** keep `store.ts` and `api.ts` as the data layer (extend them only if needed).
   Map the real fields: `callsign`, `adapter`, `project`, `branch`, `cwd`, `state`,
   `attention{active,reason,since,acknowledged,message}`, `lastEvent`, `restore`, `host`,
   `startedAt`, `updatedAt`. Regions = distinct `project` values. Activity height comes
   from the recency and rate of `lastEvent`/`updatedAt` changes kept client side (no
   contract change).
2. **Behaviour kept from today:** pairing banner and code entry (`pair-input`,
   `pair-submit`), LOS/daemon-down banner after 3 s with recovery, RESTORE (including
   capability none = "Focus manually" with no focus call, and the FOCUSED/failed result
   for 5 s), ACK, DISMISS, copy cwd, the highlight message, the assertive/polite live
   announcer, the bar's link and notify lamps (compact, in the header), ended and lost
   sessions grouped and collapsible in the list view.
3. **New:** the 3C layout, terrain canvas (HiDPI, resize-safe, colours from CSS tokens,
   back-to-front with occlusion), dragging confined to the card (Pointer Events, pointer
   capture, `touch-action:none`, inertia, clamped pitch and zoom, reset), keyboard map
   (J/K, N, Enter = restore, A, D, I details, L list, T telemetry, R readiness details,
   arrows and +/- on the focused card, 0 reset, ? help), light and dark themes, reduced
   motion (no inertia, flights or pulses; still a non-colour cue on items that need you).
   Telemetry cards show "Not wired" and a dashed sparkline; T shows the clearly labelled
   sample-data preview from the concept.
4. **Tests:** keep the ids DS-01..DS-10, CARD-01..04, GP-01..08, AX-01..04, SYS-01..06
   and rewrite their assertions to the new design (DS-06/07 become layout and typography
   checks of the new spec; DS-08 regenerates both platform screenshots against a fixture
   board). Add tests for drag-to-orbit not scrolling the page, still click selects, and
   list view containing every session. AX-01 (axe) must stay clean.
5. **Quality bar:** compare your screenshots with the concept's `3c-desk-dark-sel.png`;
   it must look as calm and polished, with real data. No console errors.
