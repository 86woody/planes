# T001: Monorepo scaffold and stubs

Milestone M0 · Wave 0a · Depends on: nothing · Runs on: any OS

## Goal

Create the pnpm workspace, every package skeleton, the shared tool configs, and a stub
for every module named in the internal contract, so that later tasks only fill in
bodies. After this task, `typecheck` and `lint` pass on an empty-but-complete tree.

## Codes against

`docs/contracts/internal.md` (all of it: sections 1, 3 and 6 verbatim, the stub list in
4, the CLI list in 7), `docs/contracts/attention.md` (the code blocks in sections 1 and 6:
signatures of `reduce`, `ReducerOptions`, `CoreEvent`, `SessionCursor`, `decide`,
`decideRenotify`, `Coalescer`, `NotifyContext`, `NotifyDecision`), `docs/contracts/ingest.md`
section 5 (the `VSCODE_NAMES`, `SHELL_NAMES`, `LINUX_TERMINALS` lists and the `classifyHost`
rule table; `classifyHost(origin: IngestOrigin): Host`), `docs/contracts/README.md`, `docs/ARCHITECTURE.md` section 1 (packages and dependency
direction), `docs/TEST-PLAN.md` section 3 (Vitest projects), `AGENTS.md` (stack lock).

## Files (create)

Root: `package.json`, `pnpm-workspace.yaml`, `tsconfig.base.json`, `tsconfig.json`,
`vitest.workspace.ts`, `eslint.config.js`, `.prettierrc.json`, `.prettierignore`,
`.gitignore`, `playwright.config.ts`, `scripts/check-toolchain.mjs`,

## Do not touch

`docs/**` (except your checkpoint), `.gitattributes`, `README.md`, `AGENTS.md`, `CLAUDE.md`.

## Steps

1. Root `package.json`: `"name": "mission-control"`, `"private": true`,
   `"type": "module"`, `"packageManager": "pnpm@<the exact output of pnpm --version on this machine, e.g. 11.2.2>"` (do not invent a newer version: pnpm downloads the pinned version and fails if it does not exist), `"engines": {"node": ">=22"}`.
   Scripts: `build` = `pnpm -r run build`, `typecheck` = `pnpm -r --if-present run typecheck`,
   `lint` = `eslint . --max-warnings 0`, `format` = `prettier --check .`,
   `test` = `vitest run`, `mc` = `node packages/cli/dist/mc.js`,
   `gate` = `node scripts/gate.mjs m5`, `gate:m0`..`gate:m4` = `node scripts/gate.mjs m0`..`m4`,
   `task:check` = `node scripts/task-check.mjs`.
   devDependencies: `typescript ^5.8.0`, `vitest ^3.2.0`, `@vitest/ui` not needed,
   `eslint ^9.30.0`, `@eslint/js ^9.30.0`, `typescript-eslint ^8.35.0`,
   `prettier ^3.6.0`, `@types/node ^24.0.0`, `@playwright/test ^1.55.0`,
   `@axe-core/playwright ^4.10.0`, `jsdom ^26.0.0`, `@testing-library/react ^16.3.0`,
   `@testing-library/dom ^10.4.0`.
2. `pnpm-workspace.yaml`: `packages: ["packages/*"]`.
3. `tsconfig.base.json`: these compilerOptions (the same set as
   `harness-tools/blackbox/tsconfig.base.json`; you do not need to open that file):
   target ES2023, module/moduleResolution NodeNext, strict, noUncheckedIndexedAccess,
   exactOptionalPropertyTypes, isolatedModules, verbatimModuleSyntax, skipLibCheck,
   declaration, sourceMap, `"composite": true`. **No `paths` and no `baseUrl`**: mapping
   `@mc/<p>` to another package's `src/` puts that file outside this package's `rootDir`
   and `tsc` fails with TS6059. Cross-package imports resolve through the pnpm workspace
   links (`node_modules/@mc/<p>` -> its `package.json` `exports`) plus TypeScript
   project references, which map `dist/*.d.ts` back to the referenced project.
4. Packages, names `@mc/<p>`, `"type": "module"`, `"version": "0.1.0"`, `"private": true`,
   `exports: {".": {"types": "./dist/index.d.ts", "default": "./dist/index.js"}}`,
   scripts `build` = `tsc -b`, `typecheck` = `tsc -b` (build mode emits `dist/` and
   `*.tsbuildinfo`; that is intended). Each `tsconfig.json` extends the base,
   `rootDir: src`, `outDir: dist`, `include: ["src"]`, and
   `"references": [{"path": "../<dep>"}]` for every `@mc/*` dependency below. Root
   `tsconfig.json` is a solution file: `{"files": [], "references": [one per package except ui and vscode-bridge]}`.
   Exception `ui`: not composite (Vite builds it); its `typecheck` is
   `tsc --noEmit -p tsconfig.json` with `"composite": false`, `"references": [{"path": "../contracts"}]`;
   `pnpm -r` runs packages in dependency order, so `contracts` is built first.
   `vscode-bridge` is handled like `ui` (not composite, `typecheck` =
   `tsc --noEmit -p tsconfig.json`, references `../contracts`), because its `dist/` is
   esbuild's CJS bundle and a `tsc` emit would overwrite it.
   Dependencies (workspace packages as `"workspace:*"`):
   - contracts: `ajv ^8.17.0`, `ajv-formats ^3.0.1`; dev `json-schema-to-typescript ^15.0.0`.
   - core: `@mc/contracts`.
   - platform: `@mc/contracts`, `koffi ^2.11.0`, `dbus-next ^0.10.2`.
   - daemon: `@mc/contracts`, `@mc/core`, `@mc/platform`, `fastify ^5.4.0`,
     `@fastify/websocket ^11.1.0`, `@fastify/static ^8.2.0`, `@fastify/cookie ^11.0.0`, `ws ^8.18.0`; dev `@types/ws ^8.18.0`.
   - hook: `@mc/contracts`, `@mc/platform`; `"bin": {"mc-hook": "./dist/mc-hook.js"}`;
     its `src/main.ts` compiles to `dist/main.js`, and `src/mc-hook.ts` (one line:
     `import "./main.js";`) to `dist/mc-hook.js`.
   - cli: `@mc/contracts`, `@mc/core`, `@mc/platform`, `@mc/daemon`; `"bin": {"mc": "./dist/mc.js"}`,
     `src/mc.ts` imports `./main.js`.
   - ui: `react ^19.1.0`, `react-dom ^19.1.0`, `@fontsource/barlow-condensed ^5.2.0`,
     `@fontsource/jetbrains-mono ^5.2.0`, `@mc/contracts` (types only); dev `vite ^7.0.0`,
     `@vitejs/plugin-react ^5.0.0`, `@types/react ^19.1.0`, `@types/react-dom ^19.1.0`.
     Scripts `build` = `vite build`, `typecheck` = `tsc --noEmit -p tsconfig.json`; tsconfig
     adds `"jsx": "react-jsx"`, `"lib": ["ES2023", "DOM"]`, `"moduleResolution": "Bundler"`, `"module": "ESNext"`.
   - vscode-bridge: `@mc/contracts` (types only; esbuild bundles nothing from it at runtime), `ws ^8.18.0`; dev `@types/vscode ^1.90.0`, `esbuild ^0.25.0`, `@types/ws ^8.18.0`, `@vscode/vsce ^3.6.0`;
     manifest fields `"publisher": "woody"`, `"engines": {"vscode": "^1.90.0"}`,
     `"main": "./dist/extension.js"`, `"activationEvents": ["onStartupFinished"]`,
     `"extensionKind": ["ui"]`; `build` = `esbuild src/extension.ts --bundle --platform=node --format=cjs --external:vscode --outfile=dist/extension.js`.
5. `packages/daemon/src/internal.ts` and `packages/ui/src/model.ts`: copy the code
   blocks of `internal.md` sections 1 and 3 verbatim.
6. Stubs: every file listed in `internal.md` sections 2, 3 (tables), 4, 6 and 7. Each
   exports exactly the frozen names with the frozen signatures; function bodies are
   `throw new Error("not implemented: T0xx")` with the owner task id (React components
   too). Types and interfaces are written in full (they are the contract). For `@mc/contracts`, create
   `packages/contracts/src/index.ts` exporting the type names listed in
   `docs/contracts/README.md` as `// eslint-disable-next-line @typescript-eslint/no-explicit-any` + `export type X = any;`
   placeholders (`any`, not `unknown`: the verbatim code indexes them, e.g. `Session["host"]`,
   `Host["kind"]`; T002 replaces the file) and the validators as stubs. For `@mc/platform`, `src/types.ts` gets the
   interface from `platform-adapter.md` section 1 verbatim (T003 owns it afterwards).
7. `vitest.workspace.ts`: the projects of TEST-PLAN section 3 exactly, each with
   `resolve.alias` mapping `@mc/<p>` to `packages/<p>/src/index.ts`, and
   `passWithNoTests: false` on every project (a project with no test files fails; that
   is intended until its task lands).
8. `eslint.config.js`: `@eslint/js` recommended + `typescript-eslint` recommended,
   ignores `**/dist/**`, `**/node_modules/**`, `.gate/**`, `packages/contracts/src/generated/**`;
   rule `no-restricted-imports` enforcing ARCHITECTURE section 1 (for files under
   `packages/core/**` ban `@mc/platform`, `@mc/daemon`, `node:*`; under `packages/ui/**`
   and `packages/vscode-bridge/**` ban `@mc/core`, `@mc/platform`, `@mc/daemon`;
   under `packages/hook/**` ban `@mc/daemon`, `@mc/core`, `fastify`).
9. `playwright.config.ts`: `testDir: "e2e"`, one project `chromium`, `workers: 1`,
   `snapshotPathTemplate: "{testDir}/__screenshots__/{arg}-{platform}{ext}"` (T033 owns `e2e/__screenshots__/**`),
   `reporter` set by the gate runner, `use.trace: "retain-on-failure"`, `retries: 0`.
10. `scripts/check-toolchain.mjs`: prints `node v<x> pnpm <y> git <z>`; exits 1 if Node
    major < 22, `pnpm --version` does not start with `11.`, or `git --version` fails.
11. `scripts/check-stubs.mjs`: a hard-coded list (from internal.md) of `{file, exports[]}`;
    for each, the file exists and its text contains `export` followed by each name;
    prints `STUBS OK <n>/<n>` or `STUBS MISSING <file>:<name>` lines and exits 1.
12. `.gitignore`: `node_modules/`, `dist/`, `.gate/`, `test-results/`, `playwright-report/`, `*.tsbuildinfo`.
13. Run `pnpm install` and commit the lockfile.

