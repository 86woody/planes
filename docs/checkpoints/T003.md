## Choices the contract left open (review these)

- `NullPlatform` and `FakePlatform` need an `os` value; the contract does not say what to use when `process.platform` is unknown. NullPlatform defaults to `"linux"` and takes an optional os argument; FakePlatform is fixed to `"linux"`.
- `NullPlatform.processAlive`: plain `process.kill(pid, 0)` existence check (EPERM counts as alive) when startTime is null; with a non-null startTime it returns false because it cannot verify the start time.
- `FakePlatform.processAlive`: start-time check applies only when startTime is non-null (PA-09 says a null startTime is a plain existence check). The `startTimes` script entry is compared only in that case.
- `FakePlatform.foregroundWindow` returns a window with `pid: 0`.
- `FakePlatform.click` calls the most recently stored onClick, not all of them.
- `createPlatform` reads `MC_PLATFORM` from `env.displayEnv()` (which overlays process.env), so tests can inject it without touching the real environment.
- Conformance PA-09 checks `processAlive(process.pid, null)` is true; FK-08 sets `alivePids` to include `process.pid` so the fake satisfies it.
- Test casts: FK-01..FK-08 build `IngestOrigin` and `Host` with `as unknown as`, since the fixtures only need the fields the fake reads.
