# T021: SessionService

Milestone M1 · Wave 2 · Depends on: T010, T012, T016 · Runs on: any OS

## Goal

The daemon's in-memory session store: applies the reducer to every event, keeps
cursors, origins and targets, numbers changes for the WebSocket, persists through
`Persistence`, and prunes old ended sessions.

## Codes against

`internal.md` section 1 (`SessionService`, `SessionRecord`, `SessionChange`,
`PersistedState`) and section 2 (`createSessionService`), `attention.md` section 1
(`reduce`, options), `config.schema.json` (`sessions.*`, `notifications.on.done`,
`adapters.*`), `ARCHITECTURE.md` section 5.

## Files

`packages/daemon/src/sessions.ts`, `packages/daemon/test/sessions.test.ts`,
`docs/checkpoints/T021.md`.

## Do not touch

Everything else. In tests, use a hand-written in-memory `Persistence` and `ConfigStore`
(simple objects implementing the interfaces), never the real modules.

## Steps

1. Construction: records from `initial.records` into a `Map`; `CallsignAllocator` with
   `initial.callsignCounter` and `inUse` = callsigns of non-ended sessions.
2. `ingest(env, receivedAt)`: if `config.adapters[env.adapter].enabled` is false, return
   the id without applying. Else `persistence.appendEvent`, call `reduce(prev, {kind:
   "ingest", envelope, receivedAt}, opts, alloc)` with `opts` from config
   (`doneIsAttention = notifications.on.done`, `capturePromptText`, shell seconds). On a
   result, store `session`, `cursor`, and `origin = env.origin`; if `changed`, emit
   `upsert` with `nextSeq()`. Always `scheduleSave`.
3. `apply(ev)`: same for non-ingest events; unknown id -> `undefined`.
4. `setRestore`, `setGit`: replace fields, emit `upsert` if anything changed.
5. `remove(id)`: delete, emit `remove`, save.
6. Pruning: on every `ingest`/`apply` and once a minute (a `setInterval` started by the
   service, `unref`ed), remove sessions in ended/lost whose `updatedAt` is older than
   `sessions.retainEndedHours`.
7. `list()` sorted by `startedAt` ascending; `records()` same order.
8. Tests, titles exactly:
   - `SS-01 first SessionStart creates a session MC-01 and emits one upsert with seq 1`
   - `SS-02 events with no public change emit nothing`
   - `SS-03 seq increases by one across upserts and removes`
   - `SS-04 disabled adapter is ignored`
   - `SS-05 ack via apply marks attention acknowledged and emits`
   - `SS-06 setRestore updates host and restore and keeps the target in the record`
   - `SS-07 remove emits a remove change and the session is gone from list()`
   - `SS-08 ended sessions older than retainEndedHours are pruned` (fake timers)
   - `SS-09 restored state from PersistedState keeps callsigns and the counter continues`
   - `SS-10 every ingest calls appendEvent and scheduleSave`
