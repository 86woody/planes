# T010: Attention reducer

Milestone M1 · Wave 1 · Depends on: M0 · Runs on: any OS

## Goal

Implement `reduce()` and `summarize()` in `@mc/core`: the pure state machine that turns
agent events into session state. Every row of the transition table becomes one test.

## Codes against

`docs/contracts/attention.md` sections 1-5 (normative), `session.schema.json`,
`ingest.schema.json`, `internal.md` section 4 (core exports). Import `classifyHost`
from `./classify.js` and `CallsignAllocator` only through the `alloc` parameter.

## Files

`packages/core/src/attention.ts`, `packages/core/src/summary.ts`,
`packages/core/test/attention.test.ts`, `packages/core/test/helpers.ts`,
`docs/checkpoints/T010.md`.

## Do not touch

`classify.ts`, `callsign.ts`, `notify-policy.ts`, `index.ts` (it already re-exports
your names), everything outside `packages/core`.

## Steps

1. `summary.ts`: `summarize(adapter, event, payload)` per attention.md section 5.
2. `attention.ts`: export `ReducerOptions`, `CoreEvent`, `SessionCursor` exactly as in
   section 1, and `reduce()`. Structure:
   - A function `newSession(env, opts, alloc)` building a full `Session` with every
     required field (id `<adapter>:<nativeSessionId>`, `callsign = alloc.nextCallsign()`,
     `title` = project until a prompt sets it, `branch: null`, `stats` zeros,
     `host: classifyHost(env.origin)` imported from `./classify.js` (T012 implements it in
     parallel; your test file replaces it with `vi.mock("../src/classify.js", ...)`
     returning a fixed Windows Terminal `Host`, so your tests never depend on T012),
     `restore: {capability: "none", reason: null, lastResult: null}`, `endReason: null`).
   - A row table: an array of `{id, match(prev, ev), apply(prev, ev)}` objects in table
     order, so the code mirrors attention.md and the first match wins.
   - Times: `new Date(ms).toISOString()`.
   - `project` = basename of `payload.cwd`: split on both `/` and `\`, drop empty
     parts, take the last. `node:path` is banned in `packages/core` by the lint rule.
   - Never mutate `prev`; return new objects. `changed` = deep inequality of public
     session (use a small JSON compare).
3. `helpers.ts`: builders `envelope(event, payload?, overrides?)` (valid `IngestEnvelope`
   with `adapter claude-code`, `nativeSessionId "s1"`, a Windows Terminal origin with
   `agent {pid: 4242, name: "claude.exe"}`, `sentAt` from an incrementing counter
   starting at 1_700_000_000_000), `opts(overrides?)`, `alloc()` returning `MC-01`, `MC-02`, ...
4. Tests: one per row, titled `SM-nn <row text>`, e.g.
   `SM-11 live + PermissionRequest -> needs_permission with "Permission: Bash"`.
   Each asserts `state`, the full `attention` object, and the "Other" column. IDs:
   SM-01..SM-28 and SM-30..SM-38 (there is no SM-29). Every assertion on the result
   also runs `validateSession` from `@mc/contracts` and expects ok.
