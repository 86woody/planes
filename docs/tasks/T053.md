# T053: Shell integration snippets

Milestone M4 · Wave 5 · Depends on: T020 · Runs on: any OS (bash tests need bash; pwsh tests need pwsh; each test asserts `which` first)

## Goal

Prompt hooks for PowerShell 7, bash and zsh that report shell sessions to the daemon
through `mc-hook shell`, without slowing the prompt.

## Codes against

`docs/contracts/ingest.md` section 6.2, `attention.md` SM-31..SM-36, D-18.

## Files

`packages/cli/assets/shell/{mc.ps1,mc.bash,mc.zsh}`,
`packages/cli/test/shell-integration.test.ts`, `docs/checkpoints/T053.md`.

## Do not touch

Everything else. The snippets call the hook with the absolute paths substituted by the
installer (T051) through the variables `MC_NODE` and `MC_HOOK_JS`, which each snippet
reads from `<stateDir>/shell.env` (`MC_NODE=...` and `MC_HOOK_JS=...` lines, written by
T051; in your tests, write it yourself).

## Steps

1. Every hook call runs in the background and discards output:
   bash/zsh `( "$MC_NODE" "$MC_HOOK_JS" shell <Event> ... >/dev/null 2>&1 & )`;
   pwsh: `[System.Diagnostics.Process]::Start($psi)` with a `ProcessStartInfo` whose
   `UseShellExecute = $false` and `CreateNoWindow = $true`, never waited on (do not use
   `Start-Process`, which costs ~100 ms per prompt).
2. Events: `ShellStart` once when sourced; `ShellCommandStart --command <first word>`
   before each command (bash: `trap ... DEBUG` guarded to fire once per prompt cycle, or
   `PS0`; zsh: `preexec`; pwsh: wrap `PSConsoleHostReadLine` / use
   `Set-PSReadLineKeyHandler -Key Enter` with `AcceptLine`); `ShellCommandEnd --exit <code>
   --duration-ms <n> --command <word>` and then `ShellPrompt` from the prompt hook
   (bash `PROMPT_COMMAND`, zsh `precmd`, pwsh `prompt` function wrapper that preserves the
   existing prompt); `ShellExit` on exit (bash/zsh `trap EXIT`, pwsh
   `Register-EngineEvent PowerShell.Exiting`).
3. Only the first word of the command line is sent (`${cmd%% *}`), never arguments.
4. The snippets do nothing if `MC_NODE` or `MC_HOOK_JS` is empty or the file is missing.
5. Tests run each available shell non-interactively with the snippet sourced and a
   fake `MC_HOOK_JS` (a Node script that appends its argv as one JSON line to a file),
   titles exactly:
   - `SH-01 bash: sourcing sends ShellStart`
   - `SH-02 bash: a command sends ShellCommandStart with the first word only, then ShellCommandEnd with exit code and ShellPrompt`
   - `SH-03 zsh: same sequence via preexec and precmd` (if zsh is absent, assert `which zsh` is null as the only assertion and record it)
   - `SH-04 pwsh: ShellStart and ShellPrompt are sent and the original prompt text is preserved` (same rule if pwsh is absent)
   - `SH-05 missing shell.env makes every snippet a silent no-op`
