## Surprises

- The launcher template needed `"\n"` in the TypeScript template literal. A plain `"\n"`
  put a real newline inside the generated JS string, so the launcher failed to parse
  (LN-07 and LN-08 caught it).
- `claude.ts`, `copilot.ts` and `codex.ts` now receive launcher paths from `hookJsPath`,
  but they do not write the launchers until T084 adds `prepareLaunchers`. Until T084 merges,
  a fresh `mc install claude-code` records a launcher path that does not exist yet. This is
  the sequencing the task file describes, not a contract change.
