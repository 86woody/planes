# T097 checkpoint

## What works

- `parseInitArgs` (packages/cli/src/commands/init.ts) accepts `--agents a,b`, `--agents a b`
  (any number of words), `--agents a, b` (comma attached to a word) and `--agents=a,b`.
  Words are collected up to the next argument starting with `--`, split on commas, trimmed,
  lower-cased, de-duplicated, empty pieces dropped. Unknown agents, an empty list, a bare
  `--agents` and any stray `--` argument return the USAGE text (exit 2 through `run`).
