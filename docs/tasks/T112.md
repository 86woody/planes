# T112: the Copilot telemetry fold (D-56)

Milestone M5 · Wave 9a · Depends on: T002 · Runs on: any OS

## Goal

A pure function set in `@mc/core` that turns Copilot `events.jsonl` lines and Copilot OTel
file records into one `Telemetry` value (`session.schema.json` `$defs/Telemetry`). No I/O,
no timers, no clock reads: time comes in as `nowMs`.

## Codes against

`docs/DECISIONS.md` D-56; `docs/contracts/session.schema.json` (`telemetry`, `$defs/Telemetry`);
`docs/contracts/internal.md` (the `packages/core/src/telemetry.ts` row).

## Files

`packages/core/src/telemetry.ts`, `packages/core/src/index.ts` (one export line),
`packages/core/test/telemetry.test.ts`, `packages/core/test/fixtures/telemetry/*.jsonl`,
`docs/checkpoints/T112.md`.

## Input shapes

**events.jsonl line:** `{"type": string, "data": object, "id": string, "parentId": string|null, "timestamp": ISO string}`.
**OTel file record:** one JSON object per line, `"type": "span"` with `name`, `startTime`, `endTime`,
`attributes`, `status`; or `"type": "metric"` with `name`, `dataPoints`. `attributes` may be a plain
object (`{"gen_ai.usage.input_tokens": 12}`) or an OTLP list (`[{"key": "...", "value": {"intValue": "12"}}]`
with `stringValue`, `intValue` (string or number), `doubleValue`, `boolValue`); read both.

## Steps

1. `createCopilotFold()` returns `{ addEventLine(line), addOtelRecord(rec), snapshot(nowMs) }`.
   `addEventLine` parses JSON; a line that does not parse, or has no string `type`, is ignored.
2. Event rules (`d` = `data`, `ts` = `Date.parse(timestamp)`):
   - `session.usage_record` (fields under `d.usage`) and `assistant.usage` (fields in `d`): add
     `inputTokens`, `outputTokens`, `cacheReadTokens`, `cacheWriteTokens`, `reasoningTokens` (missing = 0)
     to `tokens`; `calls.total += 1`; `model = model`; push to `recentCalls`
     `{at, model, input, output, failed: false, subagent: initiator === "sub-agent"}`; keep
     `timeToFirstTokenMs` and `duration` samples; `context.promptTokens = inputTokens`,
     `context.maxPromptTokens = maxPromptTokens ?? previous`, `estimatePct = min(100, 100*prompt/max)`
     rounded to 1 decimal, null when either is missing.
   - `session.usage_checkpoint`, `session.shutdown`: `credits.nanoAiu = totalNanoAiu` (newest wins).
     `session.shutdown`: `codeChanges = {linesAdded, linesRemoved}` from `d.codeChanges`; if
     `d.currentTokens` is a number, `context.promptTokens = currentTokens` and recompute `estimatePct`.
   - `session.error`: `errors.count += 1`, `errors.lastType = errorType` (cut to 64).
     `model.call_failure`: the same, plus `calls.failed += 1` and a `recentCalls` entry with
     input 0, output 0, `failed: true`. `rate_limit`: `calls.rateLimited += 1`.
   - `tool.execution_start`: remember `toolCallId -> {name: toolName, ts}`.
     `tool.execution_complete`: find the start; `runs += 1` for that name; `failed += 1` when
     `d.success === false`; a duration sample `ts - startTs`. A complete with no start counts a run
     with no duration under name `unknown`. **Never read `arguments`, `result`, `shellExecution` or
     any other field.**
   - `permission.requested`: `requested += 1`, `pending += 1`, remember `requestId -> ts`.
     `permission.completed`: if the request is known, `pending -= 1` and `waitedMs += ts - requestedTs`;
     `d.result.kind` starting `approved` -> `approved += 1`, starting `denied` -> `denied += 1`.
     `pendingSince` = ISO of the oldest still-pending request, else null.
   - `user_input.requested` / `user_input.completed`: the same for `input` (no approve/deny).
   - `subagent.started`: a new entry `{name: agentName, model: null, modelMatches: null, durationMs: null, failed: false}`.
     `subagent.completed`: the newest entry with that `agentName` gets `model`, `durationMs`,
     `modelMatches = configuredModelMatchesActual ?? null`. `subagent.failed`: `failed = true`.
     Keep the newest 20.
   - `session.compaction_complete`: `compaction.count += 1`; `compaction.tokens += compactionTokensUsed`
     when it is a number (stays null until the first number).
   - `session.snapshot_rewind` -> `rewinds`, `session.truncation` -> `truncations`,
     `session.warning` -> `warnings` (each `+= 1`).
   - `session.task_complete`: `task = {success: d.success ?? null, outcome: string d.outcome cut to 64, else null}`.
   - Known and ignored (no count): `session.start`, `session.resume`, `session.idle`, `session.info`,
     `session.model_change`, `session.context_changed`, `session.usage_info`, `user.message`,
     `assistant.message`, `assistant.turn_start`, `assistant.turn_end`, `assistant.reasoning`,
     `system.message`, `instruction.update`, `instruction.update_delivery`, `hook.start`, `hook.end`,
     `skill.invoked`, `abort`, `session.title_changed`, `session.plan_changed`, `session.todos_changed`,
     `session.mcp_servers_loaded`, `session.mcp_server_status_changed`, `session.skills_loaded`,
     `session.tools_updated`, `tool.execution_progress`, `tool.execution_partial_result`,
     `tool.shell_output`, `human_response.recorded`. Any other type: `unknownEvents += 1`.
3. OTel rules: any record adds `"otel"` to `sources` (events lines add `"events"`; order
   `["events","otel"]`). A `span` whose `github.copilot.request.type` attribute is `compaction`:
   `compaction.tokens += gen_ai.usage.input_tokens + gen_ai.usage.output_tokens`. A span named
   `invoke_agent`: add `github.copilot.nano_aiu` to an OTel credit sum; `credits.nanoAiu` uses that
   sum only while no event gave `totalNanoAiu`. Metrics records: no effect besides `sources`.
4. `snapshot(nowMs)`: `tokenRate` = sum of input + output of `recentCalls` (and calls dropped from
   it) with `at` in `(nowMs - 60000, nowMs]`; latency p50/p95 of the samples (nearest-rank), null
   with no samples; `tools` sorted by `runs` desc then name, newest 50, each with p50 and max of its
   durations; `recentCalls` newest 120, newest last; `updatedAt` = ISO of the newest timestamp seen,
   else of `nowMs`; `credits.aiCredits` always null (D-56 4); `model` null until a call.
   The result must pass `validateSession` when set as `telemetry` on a valid session.
5. Export `createCopilotFold` and the `CopilotFold` type from `packages/core/src/index.ts`.
6. Fixtures are hand-written and synthetic. Put a secret marker string `SECRET-ARGS-7731` in every
   `arguments`, `result` and message `content` field of the fixtures.

## Tests (`packages/core/test/telemetry.test.ts`)

- `TL-01` usage records: tokens, `calls.total`, `model`, `recentCalls`, `subagent` flag, context estimate.
- `TL-02` `tokenRate` counts only calls in the last 60 s (two `nowMs` values).
- `TL-03` checkpoint then shutdown: `nanoAiu` newest wins, `codeChanges`, `currentTokens` context.
- `TL-04` tools: runs, failed, p50, max, sort; `JSON.stringify(snapshot)` does not contain `SECRET-ARGS-7731`.
- `TL-05` permissions and input: approved, denied, pending, `waitedMs`, `pendingSince`.
- `TL-06` errors, `model.call_failure`, `rate_limit`, subagents, compaction, rewinds, truncations, warnings, task.
- `TL-07` bad JSON ignored; an unknown type counts in `unknownEvents`; a known ignored type does not.
- `TL-08` OTel: object and list attributes, compaction span tokens, `invoke_agent` nano-AIU fallback, `sources`.
- `TL-09` a session with `telemetry: snapshot` passes `validateSession`; `telemetry: null` passes too.
