# T030: UI shell: tokens, fonts, bar, banners, empty state

Milestone M2 · Wave 1 · Depends on: M0 · Runs on: any OS

## Goal

The page frame of the firing room: design tokens, fonts, the flight director bar, the
banners, the empty state, and `App` wiring the board together.

## Codes against

`docs/DESIGN.md` sections 1, 2 (bar, banners, empty state, background), 5 (bar lamps),
8, 9; `internal.md` section 3 (`App`, `Bar`, `Banner`, `Empty`, `BarProps`, `BoardState`).

## Files

`packages/ui/src/main.tsx`, `packages/ui/src/App.tsx`, `packages/ui/src/tokens.css`,
`packages/ui/src/global.css`, `packages/ui/src/components/{Bar,Banner,Empty}.tsx`,
`packages/ui/test/shell.test.tsx`, `docs/checkpoints/T030.md`.

## Do not touch

## Steps

1. `tokens.css`: the block of DESIGN.md section 1 verbatim.
2. `global.css`: `html, body, #root` full height; body background and grid of DESIGN.md
   2 ("Page background"), `color: var(--mc-text)`, `font-family: var(--mc-font-data)`;
   `.label` utility (label font, uppercase, `--mc-track-label`); `.data` utility
   (tabular-nums); `.sr-only`; the global reduced-motion rule: under
   `@media (prefers-reduced-motion: reduce)` and under `html[data-motion="reduce"]`,
   `*, *::before, *::after { animation: none !important; transition: none !important; }`.
   Focus ring of DESIGN.md 7 for `:focus-visible`.
3. `main.tsx`: import `@fontsource/barlow-condensed/600.css`, `/700.css`,
   `@fontsource/jetbrains-mono/400.css`, `/600.css`, `./tokens.css`, `./global.css`,
   `./card.css`, `./board.css`; `createRoot(document.getElementById("root")!).render(<App/>)`.
4. `App.tsx`: `const { board, actions } = useBoard()`; a `now` state updated every
   1000 ms with `setInterval`; on mount set `document.documentElement.dataset.theme =
   "console"` (the only theme in v1; the API does not expose `ui.*` config) and
   `dataset.motion = matchMedia("(prefers-reduced-motion: reduce)").matches ? "reduce" : "full"`.
   Render, in this order: `<Bar>` (props from `board` and the hostname of step 5),
   `<Banner board={board} actions={actions}/>`, `<PollStrip>`, `<Counts>`, `<Board>`, and the announcer
   (step 9). `sessions` for PollStrip and Counts = `board.state?.sessions ?? []`.
5. Hostname rule (exact): the daemon serves `index.html` with
   `<meta name="mc-host" content="<os.hostname()>">` (T026 injects it); `App` reads it
   with `document.querySelector('meta[name="mc-host"]')?.getAttribute("content") ?? ""`
   and passes it upper-cased to `Bar`.
6. `Bar.tsx`: DESIGN.md 2 bar exactly; testids `fd-bar`, `fd-host`, `fd-met`,
   `lamp-link`, `lamp-notify`, `lamp-focus`, `lamp-cfg` (wrap each `Lamp` in a span
   with the testid and a visible label). MET = local `HH:MM:SS` of `now`.
   Lamp colours per DESIGN.md 5.
7. `Banner.tsx`: at most one banner, priority `PAIRING REQUIRED` > `LOS: DAEMON` >
   `CONFIG: HOLD`; testid `banner`, `data-kind` = `pairing` | `los` | `config`.
   The pairing banner (DESIGN.md 2) contains a form: text input `pair-input`
   (`maxLength 9`, `autocomplete="off"`, autofocus, placeholder `XXXX-XXXX`) and button
   `pair-submit` labelled `PAIR`; submit calls `actions.pair(value.trim().toUpperCase())`;
   on `false` show `CODE REJECTED: run mc open for a new one` (testid `pair-error`).
   LOS shows only after the link has been `closed` for > 3 s (track with state + timer).
8. `Empty.tsx`: DESIGN.md 2 empty state, testid `empty`.
9. Announcer: `<div data-testid="announcer" class="sr-only" aria-live=...>`; `App` keeps
   the last announced attention per session and, when a session's attention becomes
   active, sets the text per DESIGN.md 9 (assertive for permission and error).
10. Tests (jsdom, Testing Library; mock `../src/store` to return a fixed board), titles exactly:
    - `UB-01 bar shows MET as HH:MM:SS of now and the host from meta mc-host`
    - `UB-02 LINK lamp is lit go when link is open and nogo when closed`
    - `UB-03 FOCUS lamp colour follows capabilities.focus full/window/none`
    - `UB-04 pairing banner wins over LOS and config banners and shows pair-input`
    - `UB-05 LOS banner appears only after 3 s of closed link` (fake timers)
    - `UB-06 announcer text is "MC-03 GO/NO-GO schmux" and assertive for a new permission attention`
    - `UB-07 submitting the pair form calls actions.pair with the trimmed upper-cased code; false shows pair-error`
