## Findings

1. **Fixed (T109, D-54).** After Restore of any Windows Terminal window, keyboard focus stayed on the
   tab strip, so typing did not reach the session until a click. Affects Claude Code as well; the W-
   checklist checked foreground and maximize only.
2. **Fixed (T109, D-54).** The tab rule matched Claude titles only; Copilot ("<topic> - GitHub Copilot")
   and Codex tabs are now matched.
3. **Open.** Copilot 1.0.112 sends SessionStart only with the first prompt, so a Copilot window is not
   on the board until something is typed in it (1.0.83 sent it at start-up).
4. **Open.** When the user denies or cancels a Copilot permission prompt, Copilot sends no hook, so the
   card stays "Needs permission" until the session's next event.
5. **Test harness, not product.** The keystroke helper's Alt tap puts VS Code into menu mode, which ate
   the first two characters of one prompt and one Ctrl+PgUp; an Esc first avoids it. The helper now
   re-checks the foreground window before every character.
6. **Side effect.** A pending CP-07 prompt was answered "Yes" by the Enter of the next prompt (Esc had
   not cancelled it), so `%TEMP%\mc-cp01\cp07.txt` (one line, "hi") was created. CP-05 created
   `cp05a.txt`, `cp05b.txt` and `cp05c.txt` there by design.
