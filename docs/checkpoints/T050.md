# T050 checkpoint: `mc` CLI

## What works

- `main.ts` dispatches `mc <name>`; `--help` lists commands (exit 0); no args or unknown command prints usage and exits 2.
- `start` (idempotent, `already running` path), `stop` (SIGTERM on POSIX, `taskkill /F` plus deleting daemon.json on Windows), `status` (daemon line plus one line per session), `daemon` (foreground child with forwarded signals), `open` (`--print`, `--no-pair`), `restore` (`--from-notification`, URI forms, unknown id falls back to open), `token rotate` (stop, atomic 32-byte token write, delete browser-sessions.json).
- `doctor` runs `checksFor(os, env)` from `lib/doctor-checks.ts`. Checks are data with `id`, `label`, `required`, `run()`, `fix`. Windows, macOS and Linux (backend chosen from display env, linux.md 1) sets are present, plus common checks (config parses, daemon reachable, Claude Code hook installed).
- Acceptance: `pnpm -r build && pnpm task:check T050` prints `TASK T050 PASS 16/16`, exit 0. Root `typecheck` and `lint` exit 0.

## What does not match, or is approximated

- **D-31 (CLI-08):** the title was changed to "old bearer requests get 403 after restart" to match `api.md` section 1 (bad credential 403, no credential 401). The test asserts 403 for the old token and 401 for no credential. The daemon was not touched.
- **Koffi:** `packages/cli/package.json` does not declare koffi and that file is outside my Files list. `allowSetForeground()` loads koffi through `createRequire` anchored at `packages/platform/package.json`. Skipped under `MC_PLATFORM=fake`. If the orchestrator wants it declared, that is a package.json change.
- **Daemon import:** `@mc/daemon` has no `src/index.ts`, so the CLI cannot import `resolvePaths` or `loadConfig`. `lib/paths.ts` re-implements config.md sections 1 and 2. `mc daemon` spawns `packages/daemon/dist/bin.js` rather than calling `startDaemon`.
- **Config check:** the doctor checks JSON syntax only (no Ajv in the CLI). The detail line says so.
- **Entry name:** `main.ts` exports `main(argv, io)`, matching the existing stub. The task text says `run(argv, io)`. I kept the stub's name.
- **Fake platform:** with `MC_PLATFORM=fake`, `open` and `restore` print the URL and do not launch a browser or touch the clipboard. `--print` does the same in any mode.
- **Not verified on a real desktop:** Windows toast, clipboard, opener and ASFW were not exercised outside the fake platform. The Linux backends and macOS TCC probes are only type-checked and listed by test, not run.
- **Notifications on macOS:** the doc says "not checkable", so no check is emitted for it.

## Surprises

- Fixture `packages/contracts/fixtures/ingest/cc-session-start.json` is a usable envelope for tests. The test ingests it through the real bearer route, so CLI-03 and CLI-06 do not hand-build envelopes.
- `api.md` section 3 says `/api/pair` returns 403 when Origin is not the daemon's own. The test sends the daemon's own Origin explicitly.
