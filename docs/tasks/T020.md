# T020: `mc-hook` (Claude Code, Codex, shell)

Milestone M1 · Wave 2 · Depends on: T013 · Runs on: any OS

## Goal

The short-lived process every agent event runs: read the event, keep only allowlisted
fields, fingerprint the process and terminal, POST to the daemon or spool, and never
fail, block or print.

## Codes against

`docs/contracts/ingest.md` (all; sections 1-4 and 6 normative), `ingest.schema.json`,
`config.md` sections 1-2 (paths, spool, hook-errors.log), D-03, D-11, D-12,
`@mc/platform` process exports (`ancestry`, `ttyOf`), AC-11, AC-12.

## Files

`packages/hook/src/{main,claude,codex,shell,envelope,send,paths,mc-hook}.ts`,
`packages/hook/test/{hook,codex}.test.ts`, `packages/hook/test/support/**`,
`docs/checkpoints/T020.md`.

## Do not touch

Every other package. Import from `@mc/platform` only `ancestry` and
`ttyOf` (deep import `@mc/platform/process` is not exported: use the package root).
Import from `@mc/contracts` only **types** (`import type`), so Ajv is never loaded.

## Steps

1. `paths.ts`: the config.md section 1 rules (duplicate of T014's logic; must give the
   same answers as `packages/daemon/test/fixtures/paths.json`).
2. `main.ts`: `const deadline = setTimeout(() => process.exit(0), 1500).unref()` as the
   very first statement; wrap everything in `try/catch` -> exit 0. `process.stdout.write`
   is never called. Dispatch on `argv[2]`: `claude-code` | `codex` | `shell`; unknown ->
   exit 0.
3. `claude.ts`: read stdin fully (stop at 1 MiB, then drain and discard); `JSON.parse`;
   build payload with the ingest.md section 4 table, truncation by code points, honouring
   `sessions.capturePromptText` read from `configFile` (missing or invalid -> true).
   Missing `session_id` or `hook_event_name` -> log to `hook-errors.log`, exit 0.
4. `envelope.ts`: build `origin` per ingest.md sections 2-3: `ancestry(process.ppid)`,
   the agent rule table (no command-line reads), `tty` via `ttyOf(agent.pid)` on POSIX, `console` per ingest.md 3 on Windows: koffi
   `GetConsoleWindow`, the `FreeConsole`/`AttachConsole(agent.pid)` fallback when it is 0,
   and `GetAncestor(GA_ROOTOWNER)` (declare them locally in this file; null elsewhere;
   write in your checkpoint which path produced the handle when you ran HK-01 on Windows), env allowlist with `SSH_CONNECTION -> "present"`.
   `sentAt = Math.floor(performance.timeOrigin)` (process start, ingest.md 3; never
   `Date.now()`), `seq = 0`, `v = 1`.
5. `send.ts`: read port (daemon.json, then config.json, then 47800) and token; `fetch`
   `POST http://127.0.0.1:<port>/ingest/v1/events` with `AbortSignal.timeout(800)`.
   Outcomes per ingest.md section 1 table. Spool: `mkdir -p spoolDir`, write
   `<sentAt>-<pid>-<seq>.json`, then if more than 1000 files delete the oldest by name.
   `hook-errors.log`: append `iso\tcode\tmessage\n`.
6. `codex.ts`: ingest.md 6.1 (JSON in `argv[3]`); `shell.ts`: ingest.md 6.2 flags.
7. Tests spawn the **built** hook (`node packages/hook/dist/mc-hook.js ...`; the stage
   builds it first) with `MC_HOME=<tmp>`, feeding fixtures from
   `packages/contracts/fixtures/ingest/raw/`. A tiny test HTTP server on port 0 writes
   its port to `<tmp>/state/daemon.json` and the token file, and records bodies.
   Titles exactly:
   - `HK-01 SessionStart is POSTed with nativeSessionId, event and allowlisted payload`
   - `HK-02 the envelope validates against ingest.schema.json` (validate in the test, not in the hook)
   - `HK-03 daemon down: exits 0 within 1500 ms and writes one spool file`
   - `HK-04 daemon hangs (never responds): exits 0 within 1500 ms and spools`
   - `HK-05 PermissionRequest tool_input and permission_suggestions are not sent`
   - `HK-06 env outside the allowlist is not sent; SSH_CONNECTION becomes "present"; prompt is truncated to 200 code points`
   - `HK-07 stdout is empty for every fixture`
   - `HK-08 malformed stdin: exit 0, nothing sent, one hook-errors.log line`
   - `HK-09 capturePromptText false: prompt and last_assistant_message are omitted`
   - `HK-10 spool keeps at most 1000 files, deleting the oldest`
   - `HK-11 paths.ts resolves every case in packages/daemon/test/fixtures/paths.json` (import the hook's `paths.ts` directly; unit, no spawn)
   - `CX-01 codex agent-turn-complete argument becomes an envelope with event agent-turn-complete`
   - `CX-02 codex thread-id with illegal characters is sanitised to [A-Za-z0-9._-]`
   - `CX-03 codex malformed argument exits 0 and sends nothing`
