# T123: wire the session page and the run trace into the app; key O; sheet link (D-58)

Milestone M5 · Wave 10c · Depends on: T120, T121, T122 · Runs on: any OS

## Goal

The hash routes open the session page and the run trace in place of the deck, keys and links reach
them, and the deck behaves exactly as before on `#/`.

## Steps

1. `App.tsx`: `const [route, go] = useRoute();`. The page session is
   `sessions.find((s) => s.id === route.id)` for session and run routes.
   - Route `deck`: render exactly what renders today.
   - Route `session` or `run` with the session found: inside `<main className="main">` render only
     `<SessionView ...>` (session route) or `<RunTrace ...>` (run route) instead of the side column and
     the Board; do not render the telemetry row. `SessionView` gets `onCopy={copy}`. For the run route,
     App fetches `api.traces(id)` on entering the route and every 5 s while the run shown is not
     complete and the session is live; it passes `run = runs.find(traceId) ?? null` and `loading` true
     until the first answer.
   - Route `session` or `run` whose session is not in `sessions` (after the first state arrived):
     go to the deck (`go({ page: "deck" })`).
   - Entering a session or run route also selects that session (`setSelected(id)`), so leaving with Esc
     returns to the deck with it selected; the sheet closes.
2. Keys (the listener reads the route through the existing `live` ref):
   - `o`: with a selected session, `go({ page: "session", id })`.
   - On a session or run route: `Escape` goes up one level (run -> its session, session -> deck), and is
     handled before the existing Escape chain; `j`/`k` open the next/previous session's page along the
     existing `walk`; `Enter` restores the page session as today; `?` opens help; `t` and the theme keep
     working; every other deck key (`n a d i r l 0-9 + - arrows`) does nothing.
   - On the deck every key behaves as today.
3. `Details.tsx`: in the sheet's actions, after `Copy cwd`, add
   `<a className="btn" data-testid="sheet-open" href={routeHref({ page: "session", id: s.id })}>Open session<kbd aria-hidden="true">O</kbd></a>`.
4. `Help.tsx`: add the row `O` · `the selected session's page`, after the `I` row.
5. `document.title` stays as today on every route.

`../src/components/Board.js`, `PollStrip.js`, `Counts.js` to null; stub `api.traces` with `vi.spyOn`)

  a trace id missing from the answer shows `rv-missing`.

  link to `#/s/<id>`; the help sheet lists `O`.
