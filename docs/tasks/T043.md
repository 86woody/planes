# T043: macOS discovery and focus

Milestone M3 · Wave 2 · Depends on: T003, T013 · Runs on: **macOS** if available, else any OS (unit tests only; OS rows unverified)

## Goal

Find and focus Terminal.app tabs and iTerm2 sessions by tty, VS Code and other apps via
Accessibility, zoom windows to the visible frame, detect missing permissions, and
assemble the macOS adapter.

## Codes against

`docs/platforms/macos.md` sections 1-3, 6, 7 (normative), `linux.md` 4.1-4.2 (tmux,
WezTerm, kitty commands are the same on macOS), `platform-adapter.md`, `internal.md` 6.

`packages/platform/src/macos/{index,discover,focus}.ts`,

`macos/notify.ts`, `macos/scripts/notify-*`, `process/**`, the Linux tmux module (copy
the tmux command builders you need into `macos/focus.ts`; do not import from `linux/`).

## Steps

1. Scripts exactly as macos.md shows, with JSON-escaped output (write a small
   AppleScript handler `jsonEscape(s)` replacing `\` and `"`; JXA uses `JSON.stringify`).
   Run with `exec("/usr/bin/osascript", [scriptPath, ...args])`.
2. `discover.ts`: `parseOsascriptError(stderr) -> "automation_denied" | "accessibility_denied" | "other"`
   (pure; `-1743` and `-25211`/`assistive access`); `resolveTarget` per macos.md 1-2:
   Terminal/iTerm2 by tty (only if the app is running, `pgrep -x Terminal` / `pgrep -x iTerm2`),
   VS Code and others by PID through `ax-list.js` (title list), WezTerm/kitty by env;
   tmux multiplexer: inner `{tmuxPane}`, outer from the client tty (linux.md 4.1).
   `foregroundWindow` via `frontmost.js`; `listWindows` via `ax-list.js`.
3. `focus.ts`: macos.md 3.1-3.4 exactly; maximize uses `screen-frame.js` bounds;
   Accessibility missing for an AX target -> `failed/permission_denied`.
4. `index.ts`: compose as T040 does for Windows; `capabilities()` adds issues
   `macos_accessibility_denied` (`ax-trusted.js` false) and `macos_automation_denied`
   (last osascript call classified as automation denied).
5. Fixtures: recorded osascript outputs and stderr samples for each script.
6. Tests, titles exactly (unit, any OS):
   - `MU-01 parseOsascriptError classifies -1743, -25211 and other errors`
   - `MU-02 terminal-find output parses to window id and tab index`
   - `MU-03 iterm-find falls back to the ITERM_SESSION_ID unique id after the colon`
   - `MU-04 screen-frame conversion to top-left bounds for a secondary screen above the primary`
   - `MU-05 resolveTarget for Apple_Terminal with a tty is full; without a tty is window`
   - `MU-06 focus maps automation denied to permission_denied with reason macos_automation_denied`
   - `MU-07 focus never passes raw titles into script source (arguments only)`
   - `MU-08 tmux inner selector builds switch-client, select-window, select-pane with -S socket`

   OS tests (macOS, `MC_OS_TESTS=1`), titles exactly:
   - `MO-01 screen-frame returns integer bounds with right > left and bottom > top`
   - `MO-02 frontmost returns a pid that processAlive accepts`
   - `MO-03 terminal-find with a bogus tty returns {} or a permission_denied classification and never throws`
   - `MO-04 processAlive start-time mismatch is false`
   - `MO-06 ancestry of a child process on macOS lists this process`
