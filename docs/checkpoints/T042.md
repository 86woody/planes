# T042 checkpoint: Windows toasts and registration

Branch `task/T042-win-notify`, host `dev-pc`.

## What works

- `windows/notify.ts`: `buildToastXml` (windows.md 5.2 template, every text node and
  attribute XML-escaped), `toastUri` (`restore/<encoded id>` or `open` for summary),
  `toastSilent`, `toastTag` (first 16 hex chars of SHA-256), and `createNotify` with
  `notify` (host `show`, returns `{id: tag}` or null), `withdraw` (host `remove`),
  `probe` (reg.exe checks for the AUMID and protocol keys, the DND and app-switch values,
  and the PowerShell 5.1 path; issues `windows_aumid_missing`, `windows_protocol_missing`,
  `windows_dnd_on`, `windows_app_notifications_off`), and `dispose`.
- `windows/toast-host.ts`: `createToastHost(spawnFn)` with lazy start, id-matched
  replies, 6000 ms for the first request of each process and 2000 ms after, kill and
  restart on timeout, and `dispose`. `spawnToastHost(scriptPath)` runs
  `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe` with `-NoProfile
  -NonInteractive -ExecutionPolicy Bypass -File`.
- `windows/ps/toast-host.ps1`: UTF-8 console encodings set before the first ReadLine,
  `show`, `remove`, `history` (for WO-06 and later), `ConvertTo-Json -Compress` replies,
  every operation in try/catch.
- `windows/registry.ts`: `regCommands`, `aumidCommands`, `protocolCommands`,
  `protocolCommand` (shim or direct), `restoreVbs` (windows.md 5.1 text with its guard;
  throws on a double quote in a path), `registerAumid`, `registerProtocol` (returns the
  VBS text in shim mode), and `unregisterAll`. Each takes an optional `Exec`, so tests
  inject a fake and nothing touches the real registry.
- `assets/icon-256.png`: 256x256 RGBA, black background, `#3FC1FF` chevron, produced by a
  scratch Node script that is not committed.
- Tests: WU-13 to WU-18 in `test/windows-notify.test.ts` (fake child process and fake
  timers for WU-18); WO-06 in `test/os/windows-notify.os.test.ts`, gated on
  `win32` and `MC_OS_TESTS=1`, using the test AUMID `WoodyDeus.MissionControl.Test`.
  It creates that key and deletes it in `finally`.

## Decisions

- `createNotify` builds the host from `env.repoRoot` plus
  `packages/platform/src/windows/ps/toast-host.ps1`, since `createToastHost(spawnFn)` takes no
  path. Works from the source tree; the installer already relies on the repo path.
- `config.notifications?.sound ?? true`: the schema default is true, and the generated
  type marks `notifications` and `sound` optional.
- `registry.ts` functions take the `Exec` as an optional last argument instead of through
  a factory, so the names in the contract (`registerAumid(iconPath)` and so on) hold for
  T051.
- `unregisterAll` ignores a missing key (`reg delete` fails when the key is absent).

  printed only its RUN header and wrote no report. The same file passed when run by hand
  with `MC_OS_TESTS=1`, and the second acceptance run passed 7/7 with no code change. I did
  not find a cause. It may be a one-off first-run problem, possibly PowerShell cold start.
  If it recurs, check the OS run's exit code first.

  the 6000 ms budget. WO-06 gives the history poll 2 s after the show reply, as specified.
