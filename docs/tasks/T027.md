# T027: Daemon entry, single instance, integration tests

Milestone M1 · Wave 4 · Depends on: T026, T020 · Runs on: any OS

## Goal

`startDaemon()`: create every service in the right order, listen on 127.0.0.1, write
`daemon.json`, ingest the spool, start liveness and the notifier, shut down cleanly.
Then prove the whole of M1 with real processes: a real daemon, real `mc-hook` processes.

## Steps

1. `startDaemon({env, foreground})`, in order:
   1. `paths = resolvePaths(env, process.platform, os.homedir())`; mkdir configDir and
      stateDir (`0o700` on POSIX).
   2. Single instance: if `daemonFile` exists, its pid is alive and `GET /healthz` on its
      port answers with that pid within 500 ms -> throw `AlreadyRunning {pid, port}`.
   3. `loadConfig` (fail -> throw `ConfigInvalid {errors}`); `createAuth`;
      `createPersistence`; `initial = await load()`; `createSessionService`.
   4. `platform = await createPlatform({stateDir, config, repoRoot, displayEnv})`;
      `repoRoot` = 3 levels up from `packages/daemon/dist/main.js`; `displayEnv()` returns
      `process.env` overlaid with `DISPLAY`, `WAYLAND_DISPLAY`, `XDG_CURRENT_DESKTOP`,
      `SWAYSOCK`, `HYPRLAND_INSTANCE_SIGNATURE` taken from the `origin.env` of the record
      with the newest `updatedAt` that has any of them (only for keys `process.env` lacks).
      With `MC_PLATFORM=fake`, log every FakeCall to `paths.fakePlatformFile`.
   5. `createBridgeRegistry`, `createFocusService`, `createNotifier`, `createLiveness`,
      capabilities cache (60 s TTL around `platform.capabilities()`).
   6. `buildApp(deps, {uiDir: <repoRoot>/packages/ui/dist if it exists else null, testMode: env.MC_TEST === "1"})`,
      `listen({host: "127.0.0.1", port: env.MC_PORT ? Number(env.MC_PORT) : config.port})`;
      `EADDRINUSE` -> throw `PortInUse {port}`.
   7. Write `daemonFile` `{pid, port, startedAt, version}`.
   8. Ingest the spool: for each file, `validateEnvelope`; valid -> `sessions.ingest`;
      always `deleteSpool`.
   9. Truncate `hook-errors.log` to its last 500 lines.
   10. `notifier.start()`, `liveness.start()`; resolve targets for all live records.
   11. Return `{port, stop}`; `stop()` stops liveness and notifier, closes the app,
       `persistence.flush()`, `auth.flush()`, `platform.dispose()`, deletes `daemonFile`. SIGINT/SIGTERM
       call `stop()` when `foreground`.
2. `bin.ts`: `startDaemon({env: process.env, foreground: true})`; on `AlreadyRunning`
   print `already running pid=<pid> port=<port>` and exit 0; `ConfigInvalid` print each
   error and exit 2; `PortInUse` print `port <n> in use` and exit 2.
3. Integration tests start `startDaemon` in-process with `MC_HOME=<tmp>`, `MC_PORT=0`,
   `MC_PLATFORM=fake`, `MC_TEST=1`, and spawn the built hook as a child process for
   events. Titles exactly:
   - `IT-01 a raw SessionStart piped through mc-hook appears in GET /api/state within 1 s`
   - `IT-02 PermissionRequest through mc-hook produces needs_permission and one fake notify call`
   - `IT-03 hook events while the daemon is stopped are spooled and ingested on the next start`
   - `IT-04 a second startDaemon on the same MC_HOME throws AlreadyRunning`
   - `IT-05 a session whose agent pid exits becomes ended within 10 s` (spawn a dummy `node` as the "agent": craft an envelope whose `origin.agent` is that child's pid and start time, POST it, kill the child)
   - `IT-06 restore through the API calls the fake platform focus and acknowledges attention`
   - `PS-04 restart keeps sessions and callsigns`
   - `PS-05 restart re-checks liveness: a session whose pid died while stopped is ended after start`
4. `budget.test.ts`: `BG-01 20 sessions and 2000 events keep RSS under 150 MB` (in-process
   daemon, ingest through `app.inject`-free real HTTP with `fetch`, then
   `process.memoryUsage().rss` after `global.gc` if exposed; assert < 150 * 1024 * 1024).
