# T110: the vsix is written outside the bridge package folder (D-55)

Milestone M5 · Wave 8i · Depends on: T087 · Runs on: any OS

## Goal

The Linux gate at 869f00f (2026-11-16) failed RN-04 with `ERROR ENOENT: no such file or
directory, stat 'dist/vscode-bridge-1.0.0.vsix'` (the output T104 made visible). vsce was told
`-o dist/`, the same folder it packs; it reads every file there before applying `.vscodeignore`,
so its own output could be read while being written. That explains the intermittent package
failures on both OSes (PK-07 at 290200f, RN-04 on Windows at 97b366b, the PK set on Linux at
dbff63c, RN-04 on Linux at 869f00f).

## Files

`scripts/package.mjs`, `packages/vscode-bridge/package.json` (the `package` script),
`packaging-test/version-build.test.mjs` (VR-14), `scripts/test/version.test.mjs` (VR-12, the
pinned script string), `docs/checkpoints/T110.md`.

## Steps

1. `package.mjs` runs the bridge `build`, then `vsce package -o <fresh temp dir>/vscode-bridge-<v>.vsix`,
   copies it into the package and the out dir, and removes the temp dir.
2. The bridge `package` script writes to the repo's `release/` (git-ignored), outside the package.
3. VR-14 expects `release/vscode-bridge-1.0.0.vsix` and no vsix in the bridge `dist/`.
