# T031: UI card, lamps, formatting

Milestone M2 · Wave 1 · Depends on: M0 · Runs on: any OS

## Goal

The console card in all eight states, the lamp primitive, and the formatting helpers
(labels, signals, host badges, durations, fix-it text).

## Codes against

`docs/DESIGN.md` sections 3, 4, 5, 6, 7, 8 (normative), `internal.md` section 3
(`Card`, `Lamp`, `format.ts`, `CardProps`), `session.schema.json`.

## Files

`packages/ui/src/components/Card.tsx`, `packages/ui/src/components/Lamp.tsx`,
`packages/ui/src/card.css`, `packages/ui/src/format.ts`,
`packages/ui/test/card.test.tsx`, `packages/ui/test/fixtures.ts`,
`docs/checkpoints/T031.md`.

## Do not touch

Every other UI file. Do not import `store.ts` or `api.ts`; the card gets everything
through `CardProps`.

## Steps

1. `format.ts`:
   - `stateLabel(s)`: DESIGN.md 4 label column; `needs_input` returns `HOLD`
     (the card appends the time in state itself); `needs_permission` with acknowledged
     attention returns `GO/NO-GO · ACK` (attention.md 2.1).
   - `signalOf(s)`: starting `tminus`, working `ascent`, needs_permission and error `nogo`,
     needs_input `hold`, idle `go`, ended and lost `los`.
   - `hostBadge(h)`: the DESIGN.md 3 host badge texts; `vscode-extension` -> `VS CODE · CLAUDE`;
     `linux-terminal` -> `h.app` upper-cased (or `TERMINAL` if null); append ` + TMUX`
     when `h.multiplexer`.
   - `hms(ms)`: `HH:MM:SS`, hours not capped (e.g. `123:04:05`), negative -> `00:00:00`.
   - `age(ms)`: `<n>s` under 60 s, `<n>m` under 60 m, else `<n>h`.
   - `fixText(reason, detail)`: DESIGN.md 6 table; `platform_error` -> detail; null -> `""`.
2. `Lamp.tsx`: DESIGN.md 5. `<span class="lamp" data-color data-lit data-blink>`;
   `blink` adds the class `lamp--blink`.
3. `Card.tsx`: DESIGN.md 3 anatomy with every testid in the table; `data-state` =
   `session.state`; `data-attention` = `active|acked|none`; DESIGN.md 4 treatments via
   CSS classes `card--<state>`, `card--attn`, `card--acked`, `card--done`.
   - Elapsed: `T+ ` + `hms(now - startedAt)`; state starting shows `T-MINUS` only.
   - HOLD label: `HOLD ` + `hms(now - attention.since)` when needs_input.
   - RESTORE (DESIGN.md 7): disabled with `NO SIGNAL` when ended; `SLEWING` when
     `pending`; when `restore.capability === "none"` clicking calls `actions.copyCwd(id)`
     instead of `actions.restore(id)`.
   - Result chip: `result` prop (the parent clears it after 5 s): FOCUSED / WINDOW ONLY /
     FLASHED / `NO-GO <CODE upper-cased>`; if `result.detail === "FOCUS MANUALLY"` the
     chip reads `FOCUS MANUALLY` (hold colour) regardless of code (T032 creates that
     synthetic result for capability `none`).
   - ACK visible only if `attention.active && !attention.acknowledged`; DISMISS only for
     ended and lost.
   - `highlighted` adds `card--highlight` (2px `--mc-ascent` outline for 3 s, set by parent).
   - `aria-labelledby` the callsign element id `cs-<session.id>`.
4. `card.css`: all card styles using only `var(--mc-*)` tokens (no raw colours except
   `#000` and `rgba(255,255,255,…)` where DESIGN.md writes them); blink keyframes with
   `steps(1)`; working trace; acquisition sweep; hazard band; reduced-motion outline
   fallback under `html[data-motion="reduce"]` and the media query.
5. `test/fixtures.ts`: `sessionIn(state, patch?)` loading
   `packages/contracts/fixtures/sessions/<state>.json` and applying a deep patch.
6. Tests, titles exactly:
   - `UC-01 stateLabel and signalOf cover all 8 states`
   - `UC-02 hostBadge texts including VS CODE · CLAUDE and + TMUX`
   - `UC-03 hms and age formatting edge cases`
   - `UC-04 fixText returns the DESIGN.md text for every RestoreReason`
   - `UC-05 card renders every testid of the anatomy table for a working session`
   - `UC-06 starting card shows T-MINUS and no elapsed value`
   - `UC-07 needs_input card shows HOLD with time in state`
   - `UC-08 unacknowledged permission card has card--attn and a blinking lamp; acknowledged has neither blink nor ACK and reads GO/NO-GO · ACK`
   - `UC-09 idle with done attention shows the MECO tag until acknowledged`
   - `UC-10 ended card has RESTORE disabled with NO SIGNAL and shows DISMISS`
   - `UC-11 capability none: RESTORE calls copyCwd not restore`
   - `UC-12 result chip text for focused, focused_window_only, flashed and permission_denied`
